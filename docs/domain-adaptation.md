# 领域适配指南

FinanceOS 的**核心框架是领域无关的**——角色轴、生命周期、调度引擎、风险分层都不变。适配新领域只需要替换知识库（KB）的内容。

## 适配清单

### 第一步：定义 L1 规则（强制约束）

替换 `kb/L1-rules/` 下的三个文件：

| 文件 | 内容 | 怎么改 |
|------|------|--------|
| `anomaly-thresholds.md` | 异常阈值标准 | 定义你行业的异常判定阈值（绝对值+比例） |
| `data-masking.md` | 脱敏标准清单 | 定义你行业必须脱敏的数据类型 |
| `permission-tiers.md` | 权限分级 | 定义操作权限层级 |

**示例**（制造业）：

```markdown
# 异常阈值标准（制造业）

## 核心指标
| 指标 | 触发阈值 | 黄色 | 橙色 | 红色 |
|------|---------|------|------|------|
| 毛利率偏离 | >3pp | 单月 | 连续2月 | 连续3月 |
| 存货周转天数 | >10天 | 同上 | 同上 | 同上 |
| 产能利用率 | <5pp | 同上 | 同上 | 同上 |
```

### 第二步：定义 L2 模板（输出格式）

替换 `kb/L2-templates/` 下的三个文件：

| 文件 | 内容 | 怎么改 |
|------|------|--------|
| `monthly-analysis.md` | 月度分析模板 | 改成你行业的报告骨架 |
| `quarterly-analysis.md` | 季度分析模板 | 同上 |
| `special-report.md` | 专项分析模板 | 同上 |

**关键**：报告骨架的章节结构要匹配你行业的管理习惯。比如制造业可能关注"产能利用率""存货周转"，而服务业关注"客单价""复购率"。

### 第三步（可选）：编写 L2.5 任务模板

如果行业有高频任务（如制造业的"月度成本差异分析"、金融业的"月度风控报告"），编写专门的任务模板。

格式参考 `kb/L2.5-task-templates/monthly-budget-analysis.md`。

### 第四步（可选）：建立 L3 案例库

实际运行几次后，把好的处理经验写入 L3 案例库，标注 `[提炼]` 可复用。

## 适配示例

### 从水务 → 制造业

| 需要改的 | 水务原文 | 制造业替换 |
|---------|---------|-----------|
| 核心指标 | 产销差率、水费回收率 | 毛利率、产能利用率、存货周转 |
| 分项成本 | 制水/输配/污水 | 原材料/直接人工/制造费用 |
| 管理费用 | 制水人员、管网维护 | 车间管理、质量检验 |
| 脱敏标准 | 水价、供水量 | 客户名称、单价、配方 |
| 报告章节 | 水量与产销差分析 | 产能与交付分析 |

### 从水务 → 金融

| 需要改的 | 水务原文 | 金融替换 |
|---------|---------|-----------|
| 核心指标 | 产销差率 | 不良率、ROA、净息差 |
| 风险分层 | Gate-L/M/H/X | 信用/市场/操作/流动性风险 |
| 脱敏标准 | 客户水费 | 客户身份、交易金额 |

## 不变量（不改的部分）

以下内容**跨领域通用，不需要修改**：

- `core/FINANCEOS_SYSTEM.md` 中的调度引擎
- 角色轴定义（数据分析师/报告撰写员/知识管家）
- 生命周期五阶段（感知→研判→执行→交付→沉淀）
- 四维校验（勾稽/异常/口径/格式）
- 三色预警体系（🟡🟠🔴）
- 风险分层（Gate-L/M/H/X）
- Token 三级加载机制

## 贡献你的领域适配

如果你完成了某个领域的适配并验证通过，欢迎贡献到 `examples/` 目录！

目录结构：
```
examples/{domain}/
├── README.md              # 领域说��
├── kb/
│   ├── L1-rules/          # 该领域的规则
│   ├── L2-templates/      # 该领域的��板
│   ├── L2.5-task-templates/
│   └── L3-cases/
└── CHANGELOG.md
```

提交 PR 到 `examples/` 目录即可。详见 [CONTRIBUTING.md](../CONTRIBUTING.md)。
