# 水务/公用事业领域示例

> 本目录展示 FinanceOS 在水务/公用事业领域的完整适配。这是 FinanceOS 的**原始领域**（origin domain），KB 内容经过水务企业财务总监的实际使用和验证。

## 领域特征

| 维度 | 水务/公用事业 |
|------|-------------|
| 行业特点 | 自然垄断、重资产、价格管制、民生保障 |
| 核心指标 | 产销差率、水费回收率、经营现金流、资产负债率 |
| 成本结构 | 制水（原水/电费/药剂/人工/折旧）+ 输配（管网维护/泵站电费）+ 管理+财务 |
| 定价机制 | 政府定价（水价监审），收入端弹性小 |
| 融资特征 | 依赖政府注资/化债、政策性贷款、专项债 |
| 合规要求 | 国资委/财政部报送、水价成本监审、环保合规 |
| 季节特征 | 6-9月旺季（供水高峰），电费/药剂费季节性波动大 |

## 与通用框架的差异

水务领域 KB 相比通用 FinanceOS 做了以下特殊适配：

1. **L1 异常阈值**：按水务成本科目（制水/输配/污水/管理/财务）分项设置阈值，含季节性豁免（6-9月旺季阈值上浮20%）
2. **L2 报告模板**：含"水量与产销差分析"专章、"化债注资进度"追踪
3. **L3 案例**：涵盖首月运营、旺季成本波动、季度综合分析的完整场景

## KB 文件清单

见 `../../kb/` 目录。核心 L1 规则包括：

- 产销差率 / 水费回收率 / 经营现金流 / 利润总额 / 资产负债率 阈值
- 制水/输配/污水/管理/财务费用各科目的分项阈值
- 水务行业特定的脱敏标准（水价、供水量、客户信息）

## 使用方式

直接使用 `core/FINANCEOS_SYSTEM.md` + `kb/` 目录即可，无需额外配置。

如果你是水务行业的财务人员，这就是为你准备的完整方案。
