> 效力等级：L1 强制约束 · 红线不可违反
> 适用：FinanceOS 成本费用分类管控、预算执行监控、超支审批与归因分析

## 一、适用范围

本制度适用于公司成本费用的分类管控、预算执行监控、超支审批与归因分析。AI 在处理成本费用相关分析任务时，须遵循本制度的分类标准和管控要求。

---

## 二、成本费用分类

### 2.1 按性质分类（7 类）

| 类别 | 包含内容 | 管控重点 |
|------|---------|---------|
| 人工成本 | 工资、社保、公积金、福利费、工会经费、教育经费 | 总额控制，人均效能 |
| 材料成本 | 原材料、辅助材料、备品备件 | 单价 + 用量双控 |
| 外委费用 | 外包服务、委托加工、技术咨询 | 合同管控，比价采购 |
| 折旧摊销 | 固定资产折旧、无形资产摊销、长期待摊 | 刚性支出，预算单列 |
| 管理费用 | 办公费、差旅费、招待费、会议费、车辆费等 | 定额管控，厉行节约 |
| 财务费用 | 利息支出、手续费、汇兑损益 | 融资结构优化 |
| 税费 | 增值税、企业所得税、印花税、房产税等 | 合规申报，合理筹划 |

### 2.2 按弹性分类

| 类型 | 特征 | 管控方式 |
|------|------|---------|
| 固定成本 | 不随业务量变动（折旧、租金、基本工资） | 预算总额控制 |
| 变动成本 | 随业务量同向变动（材料、计件工资） | 单位成本标准控制 |
| 半变动成本 | 有基数但随业务量浮动（水电、维修） | 基数 + 弹性系数 |

### 2.3 按预算管控分类

| 类型 | 管控方式 |
|------|---------|
| 预算内支出 | 按正常审批流程执行 |
| 超预算支出 | 须走预算调整程序 |
| 计划外支出 | 须说明必要性，走专项审批 |

## 三、预算监控规则

### 3.1 执行监控

| 规则 | 要求 |
|------|------|
| 月度监控 | 每月对比预算与实际，差异率 >10% 纳入分析 |
| 预警阈值 | 单项差异率 >20% 标记预警，须归因说明 |
| 累计监控 | 不仅看当月，还要看累计执行率是否偏离时间进度 |
| 刚性约束 | 年度预算总额不得突破，超支须走预算调整程序 |

### 3.2 监控分级

| 差异率 | 级别 | 处理方式 |
|--------|------|---------|
| ≤10% | 正常 | 常规监控，无需额外动作 |
| >10% 且 ≤20% | 关注 | 纳入分析，说明原因 |
| >20% | 预警 | 标记预警，必须归因说明并提出纠偏措施 |

## 四、五因素归因模型

超支项须区分以下五类因素，逐项归因：

| 因素 | 定义 | 典型场景 | 处理要求 |
|------|------|---------|---------|
| **政策性因素** | 国家政策调整导致的成本增加 | 社保基数上调、税率变动、环保标准提高 | 标注"政策性"，单独列示，不计入管理考核 |
| **市场性因素** | 原材料涨价、利率变动等市场原因 | 大宗商品涨价、贷款利率上浮 | 评估影响持续性，提出对冲建议 |
| **管理性因素** | 管理不善导致的浪费、效率低下 | 采购价格偏高、能耗超标、人员冗余 | 必须提出纠偏措施和整改时限 |
| **一次性因素** | 非经常性支出 | 一次性维修、诉讼费用、资产处置损失 | 说明原因即可，剥离后不参与趋势判定 |
| **趋势性因素** | 持续性的成本上升 | 人工成本逐年增长、设备老化维修递增 | 须提出结构性调整方案 |

**归因规则**：
- 一次性因素：说明原因即可，不纳入趋势判定
- 趋势性因素：必须提出纠偏措施和整改时间表
- 固定成本超支：通常指向管理问题，重点排查管理性因素
- 变动成本超支：需结合业务量判断，先剥离量差再看价差

## 五、紧急支出规则

| 规则 | 要求 |
|------|------|
| 适用场景 | 突发安全事故、自然灾害、监管紧急要求等不可预见事项 |
| 先行执行 | 可先执行后补审批，但须经财务总监口头同意 |
| 补审时限 | 须在 3 个工作日内补齐审批手续 |
| 事后归因 | 纳入当月成本分析，按五因素模型归因 |
| 额度限制 | 单笔紧急支出不超过 [待用户补充] 万元；超过须报总经理审批 |

---

## 六、超预算审批程序

| 超支类型 | 审批要求 |
|---------|---------|
| 计划内、预算内 | 按正常审批流程执行 |
| 计划内、超预算 | 须说明原因，财务总监审批 |
| 计划外支出 | 须走预算调整程序，说明必要性 |
| 紧急支出 | 可先执行后补审批，但须在 3 个工作日内补齐手续 |

---

## 七、AI 处理规则

- 成本分析须按分类标准逐项展开，不笼统合并
- 超支归因必须区分"一次性"和"趋势性"——前者说明原因即可，后者须提出纠偏措施
- 固定成本超支通常指向管理问题，变动成本超支需结合业务量判断
- 累计执行率偏离时间进度 >10% 须主动预警
- 归因分析须引用五因素模型，逐项标注因素类型
