# 脱敏标准清单

> 效力等级：L1 强制约束 · 红线不可违反
> 适用：FinanceOS 数据缓冲区入口 + 交付前 + 报送前
> 版本：v1 · 2026-07-30

---

## 一、总则

1. 脱敏范围按本清单执行，非每次自由确认
2. 用户可设"预设脱敏方案"——同类型操作自动执行，不再每次确认
3. 仅特殊场景（如报送需保留单位名称）才需逐次确认
4. 涉密文件不进入缓冲区，不处理

---

## 二、脱敏项与处理方式

| 脱敏项 | 标准处理方式 | 例外情况 |
|--------|------------|---------|
| 单位名称 | 统一替换为"本公司"或"某管网公司" | 对外报送材料需保留正式名称时，经财务总监确认 |
| 人名 | 统一替换为"某总""某经理"或岗位代号 | 无例外 |
| 银行账号 | 完全删除或用 `****` 替换 | 无例外 |
| 身份证号 | 完全删除或用 `****` 替换 | 无例外 |
| 合同编号 | 统一替换为"HT-XXX" | 无例外 |
| 金额（万元以下） | 保留精确值 | 无 |
| 金额（万元以上） | 模糊化为区间（如"50-60万"） | 内部分析时可保留精确值，经财务总监确认 |
| 涉密文件 | 不进入缓冲区，不处理 | 无例外 |
| 项目名称 | 替换为"项目A""项目B" | 对外报送时经确认可保留 |

---

## 三、水务国企专项脱敏项

> 以下为市属公用事业/水务类国企特有脱敏点，基于行业特性补充。

| 脱敏项 | 标准处理方式 | 例外情况 |
|--------|------------|---------|
| 水费数据（居民用水量） | 不外发；内部分析时模糊化为区间 | 无例外（涉及用户隐私） |
| 水费数据（工业用水量） | 内部分析保留；对外报送模糊化 | 经财务总监确认可保留 |
| 管网坐标/走向 | 不进入缓冲区，不处理 | 无例外（基础设施安全） |
| 水价监审材料 | 不进入缓冲区；如需分析，仅引用结论不引用过程 | 涉密等级高的不处理 |
| 化债注资信息 | 内部分析保留；对外报送按标准清单脱敏 | 涉密等级高的不进入缓冲区 |
| 城投平台关联信息 | 统一替换为"关联平台A""关联平台B" | 对外报送时经确认可保留 |

---

## 四、预设脱敏方案

用户可设定预设方案，匹配任务类型自动套用：

### 方案一：内部分析默认方案
- 单位名称：保留
- 人名：脱敏（替换为岗位代号）
- 金额：全部保留精确值
- 水费数据：保留
- 管网坐标：不进入缓冲区
- 其余按标准清单

### 方案二：对外报送默认方案
- 单位名称：按标准清单脱敏（例外需确认）
- 人名：脱敏
- 金额（万元以上）：模糊化为区间
- 水费数据：模糊化或删除
- 管网坐标：不进入缓冲区
- 化债注资信息：按标准清单脱敏
- 其余按标准清单

### 方案匹配逻辑
- 任务类型为"内部分析/经营分析/预算编制" → 自动套用方案一
- 任务类型为"对外报送/上报材料/巡视汇报" → 自动套用方案二
- 仅特殊场景（如报送需保留单位名称）才逐次确认

---

## 五、脱敏 gate 三环节

| 环节 | gate 内容 | 不可跳过的原因 |
|------|----------|--------------|
| 数据进入缓冲区前 | 按标准清单脱敏 | 防止敏感数据进入 AI 拥有的资源层 |
| 交付前 | 按标准清单确认脱敏范围 | 最终交付物的安全边界 |
| 报送前 | 确认报送内容、格式、接收方 | 对外报送不可撤回 |

---

## 六、残留数据清除规程

| 维度 | 规程 |
|------|------|
| 清理时机 | 任务完成后立即清理，不留过夜 |
| 清理范围 | 缓冲区内的原始数据文件 |
| 结论中的数据引用 | 允许引用分析结论（如"执行率 92%"）；不允许引用原始数据行（如"7月15日支付XXX公司50万元"） |
| 交付前检查 | 扫描产出文件，确认无原始数据残留 |
| 清理确认 | 记录清理时间和清理人，留痕可追溯 |
