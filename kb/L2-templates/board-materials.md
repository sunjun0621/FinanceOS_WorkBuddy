## 模板说明

本模板为董事会汇报材料的**格式骨架**，规定章节结构与表格样式。

与月度/季度报告的区别：董事会材料是**决策导向型报告**——不是简单罗列数据，而是围绕"需要董事会知道什么、决定什么"组织内容。核心原则：
- **每个问题必须有对应措施**：提出问题而不给方案 = 不合格
- **每个决策事项必须有选项**：不给选项只给一个方案 = 绑架决策
- **结论先行**：董事时间宝贵，先说结论再展开

风险等级：T3（对外报送级），须执行脱敏 + 审计三段。

## 报告格式骨架

### 标题区

```
[公司名称]董事会汇报材料

汇报主题：[一句话概括本次汇报核心事项]
汇报人：[姓名/职务]
汇报日期：[YYYY-MM-DD]
密级：[内部 / 秘密]
```

### 正文结构

#### 一、汇报背景

##### （一）汇报目的

- 简要说明本次汇报的背景和目的
- 明确需要董事会关注 / 决策的核心事项（1-2 句话）

##### （二）汇报范围

- 涉及的业务范围、时间范围
- 数据截止日及口径说明

#### 二、经营现状

##### （一）核心指标

**表格：主要经营指标完成情况**

| 指标 | 单位 | 本年预算 | 本年实际 | 差异 | 执行率 | 去年同期 | 同比变动 |
|------|------|---------|---------|------|--------|---------|---------|
| 营业收入 | 万元 | | | | | | |
| 营业成本 | 万元 | | | | | | |
| 利润总额 | 万元 | | | | | | |
| 经营现金流 | 万元 | | | | | | |
| 资产负债率 | % | | | | | | |

- 总体评价（一句话结论先行，加粗）
- 与预算对比：完成 / 偏离及原因概要
- 与同期对比：改善 / 恶化及原因概要

##### （二）重点工作进展

- 工作项 1：进展、成效、当前状态
- 工作项 2：进展、成效、当前状态
- 工作项 3：进展、成效、当前状态

（每项不超过 3 行，附关键里程碑节点）

#### 三、问题分析

> **编写要求**：本章节每个问题必须在第四章有对应措施，不允许"只提问题不给方案"。

##### （一）问题 1：[问题名称]

- **问题描述**：具体现象（附数据）
- **原因分析**：根因（区分内部 / 外部、主观 / 客观）
- **影响程度**：对利润 / 现金流 / 预算执行的影响金额
- **对应措施**：→ 见第四章措施 1

##### （二）问题 2：[问题名称]

- **问题描述**：具体现象（附数据）
- **原因分析**：根因
- **影响程度**：影响金额
- **对应措施**：→ 见第四章措施 2

（按重要性排序，一般不超过 3-4 个问题）

#### 四、应对措施

> **编写要求**：与第三章问题一一对应，每项措施须明确责任部门和完成时限。

##### （一）措施 1（对应问题 1）

- **措施内容**：具体做什么
- **预期效果**：量化目标（金额 / 比例 / 时间节点）
- **资源需求**：需要投入的资源（人力 / 资金 / 政策）
- **责任部门**：[部门名称]
- **完成时限**：[YYYY-MM-DD]

##### （二）措施 2（对应问题 2）

- **措施内容**：具体做什么
- **预期效果**：量化目标
- **资源需求**：需要投入的资源
- **责任部门**：[部门名称]
- **完成时限**：[YYYY-MM-DD]

#### 五、需要董事会决策的事项

> **编写要求**：每个决策事项必须提供 2 个以上方案选项，并给出推荐方案及理由。不允许"只给一个方案让董事会批准"。

##### （一）事项 1：[事项名称]

- **事项描述**：需要决策的具体内容
- **方案选项**：

| 方案 | 内容概要 | 优势 | 劣势 | 财务影响 |
|------|---------|------|------|---------|
| 方案 A | | | | |
| 方案 B | | | | |

- **推荐方案**：方案 [X]
- **推荐理由**：[从财务影响、风险、可行性等角度说明]
- **提请决议**：请董事会审议并决议采用方案 [X]

##### （二）事项 2：[事项名称]

- **事项描述**：需要决策的具体内容
- **方案选项**：

| 方案 | 内容概要 | 优势 | 劣势 | 财务影响 |
|------|---------|------|------|---------|
| 方案 A | | | | |
| 方案 B | | | | |

- **推荐方案**：方案 [X]
- **推荐理由**：[说明]
- **提请决议**：请董事会审议并决议采用方案 [X]

#### 六、附录

- 关键指标明细表
- 决策事项支撑材料（评估报告 / 方案对比详情）
- 审计三段（T3 风险等级必须包含，按 `[L1:权限分级#二]`）
- 数据来源及口径说明

## 格式规范

| 维度 | 规范 |
|------|------|
| 文件格式 | docx（党政公文格式，参照 `[L2:GB/T 9704-2012 公文格式规范]`） |
| 字体 | 标题方正小标宋 / 正文仿宋_GB2312 |
| 字号 | 标题二号 / 正文三号 |
| 行距 | 1.5 倍 |
| 表格 | 三线表，表头加粗 |
| 图表 | 配色简洁，适合公文嵌入 |
| 页边距 | 上 3.7cm / 下 3.5cm / 左 2.8cm / 右 2.6cm |
| 篇幅 | 正文控制在 5-8 页 |
| 标题层级 | 一级用"一、二、三"，二级用"（一）（二）（三）" |

## 质量检查清单

| 检查项 | 要求 |
|--------|------|
| 问题-措施对应 | 第三章每个问题在第四章有对应措施，无遗漏 |
| 决策事项完整性 | 每个决策事项有 ≥2 个方案选项 + 推荐方案 + 推荐理由 |
| 数据一致性 | 核心指标与月度/季度报告数据一致，口径可追溯 |
| 篇幅控制 | 正文 5-8 页，附录另计 |
| 脱敏检查 | T3 风险等级须按 `[L1:脱敏标准清单#三]` 执行 |
| 审计三段 | 包含编制人、复核人、审批人签署栏 |

## 调用说明

数据分析师产出经营分析结论后，报告撰写员引用本模板生成董事会汇报材料：
1. 读取本模板骨架
2. 从月度/季度报告中提取核心指标数据，填入"经营现状"章节
3. 识别经营问题 → 按"问题-措施对应"原则组织第三、四章
4. 梳理需董事会决策事项 → 按"选项+推荐+理由"原则组织第五章
5. 按 `[L1:异常阈值标准]` 确认数据标注
6. 执行校验收尾（勾稽 / 口径 / 格式 / 问题-措施对应性 / 篇幅）
7. 按 `[L1:脱敏标准清单#三]` 执行脱敏处理
8. STOP gate：T3 风险等级——脱敏确认 + 报送内容确认 + 决策事项措辞确认
