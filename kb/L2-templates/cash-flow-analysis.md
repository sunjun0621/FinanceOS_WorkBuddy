## 格式骨架

```
现金流分析报告

报告主题：XXX 现金流分析
报告期间：YYYY年MM月（或 YYYY年MM月-YYYY年MM月）
编制单位：XXX
编制日期：YYYY-MM-DD

---

一、现金流总体概况

   （一）三流量总览
   - 经营活动现金流量净额
   - 投资活动现金流量净额
   - 筹资活动现金流量净额
   - 现金及现金等价物净增加额

   （二）结构特征
   - 三流量占比与贡献
   - 与去年同期 / 预算对比

二、经营活动现金流分析（核心）

   （一）收现质量
   - 销售收现比 = 销售商品提供劳务收到的现金 / 营业收入
   - 盈余现金保障倍数 = 经营活动现金流净额 / 净利润

   （二）付现结构
   - 购买商品接受劳务付现、支付给职工、支付的各项税费占比

   （三）异常识别
   - 引用 [L1:异常阈值标准] 做偏离标注与分色定级

三、利润与现金流背离分析

   （一）背离确认
   - 净利润 vs 经营活动现金流净额：方向 / 幅度差异

   （二）差额分解
   - 应计项目变动（应收 / 应付 / 存货）
   - 非付现成本（折旧摊销）
   - 营运资本占用

   （三）归因
   - 内部：信用政策、库存管理、票据结算
   - 外部：客户回款节奏、行业周期
   - 参考 [L3:case-005-profit-vs-cashflow]

四、投资与筹资活动现金流分析

   （一）投资活动
   - 资本性支出付现 vs 预算 → 参考 [L3:case-011-capex-variance]
   - 投资收回 / 投资收益

   （二）筹资活动
   - 融资净流入、还本付息、分红
   - 与 [L1:资金管理办法] 衔接（监控指标、大额预警）

五、自由现金流与缺口预警

   （一）自由现金流 FCF = 经营活动现金流净额 - 资本性支出

   （二）资金缺口测算
   - 未来 N 月付现压力 vs 可动用资金
   - 引用 [L1:资金管理办法#监控指标]

   （三）预警信号
   - 经营活动现金流持续为负
   - FCF 为负且筹资能力（授信 / 再融资）下降

六、结论与建议

   （一）主要结论
   （二）管理建议（措施 / 责任部门 / 完成时限）
   （三）风险提示

---

数据来源：XXX
数据口径：XXX
关键假设：XXX
```

---

## 格式要求

- 标题层级：一级用"一、二、三"，二级用"（一）（二）（三）"
- 三流量必列表，且须满足勾稽：**经营 + 投资 + 筹资 = 现金及现金等价物净增加额**（等式必须成立）
- 背离分析须同时给出方向（增 / 减）与幅度（%）
- 收现质量两类指标（销售收现比、盈余现金保障倍数）为必填，缺口预警须引用资金管理办法
