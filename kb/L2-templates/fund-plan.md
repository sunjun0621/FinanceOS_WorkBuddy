## 模板说明

本模板为月度资金收支计划表的**格式骨架**，规定五大章节结构与表格样式。

核心原则：
- **五大章节不可缺**：期初余额 → 预计收入 → 预计支出 → 余缺测算 → 资金调度
- **刚性支出与弹性支出分开列示**：资金紧张时优先保障刚性支出
- **金额单位统一**：万元，保留两位小数
- **时间精度**：精确到旬（上旬 / 中旬 / 下旬）或具体日期
- **依据可追溯**：每笔收支须注明合同依据或制度依据
- **缺口不留白**：有缺口必须明确调度方案

## 编制要求

| 要求 | 说明 |
|------|------|
| 编制时点 | 每月 25 日前编制下月计划 |
| 执行跟踪 | 每周对照实际执行情况更新，计算执行率 |
| 偏差分析 | 期末与预算对比，分析偏差原因 |
| 预警规则 | 连续两个月执行率低于 85% 须重新评估编制方法 |
| 刚性优先 | 资金紧张时，优先保障刚性支出（工资、税费、到期债务） |
| 缺口必填 | 有缺口必须明确调度方案，不允许留空白 |

## 调用说明

资金管理员完成收支预测后，引用本模板生成正式资金计划表：
1. 读取本模板骨架
2. 从银行系统获取期初余额数据，填入第一章
3. 从业务部门 / 合同系统获取预计收入，按经营性 / 非经营性分类填入第二章
4. 从合同台账 / 预算系统获取预计支出，按刚性 / 弹性分类填入第三章
5. 自动计算第四章余缺测算
6. 如有缺口 → 填写第五章调度方案
7. 执行校验：
   - 收支平衡校验：期初 + 收入 - 支出 = 期末余额
   - 刚性支出保障校验：可用资金 ≥ 刚性支出合计
   - 依据完整性校验：每笔收支是否填写依据列
8. STOP gate：资金计划审批确认（编制人 → 复核人 → 审批人）
