# GB/T 9704-2012 党政机关公文格式规范

> 效力等级：L2 形式规范 · 格式标准
> 适用：所有 AI 生成报告的排版与格式控制
> 版本：v1 · 2026-07-30
> 引用依据：GB/T 9704-2012《党政机关公文格式》
> 关联：所有 L2 模板的格式规范章节均引用本规范

---

## 规范说明

本规范为机器可读的公文格式标准，供 AI 生成 docx 报告时直接调用。所有 L2 模板的格式规范章节均指向本文件，避免各模板重复定义格式参数。

适用范围：月度经营分析报告、季度财务分析报告、专项分析报告、董事会汇报材料、资金计划表等所有正式输出文件。

## 字体与字号

### 标题

| 元素 | 字体 | 字号 | 对齐 | 备注 |
|------|------|------|------|------|
| 公文标题 | 方正小标宋简体 | 二号（22pt） | 居中 | 回行时词意完整 |
| 副标题 | 楷体_GB2312 | 三号（16pt） | 居中 | 破折号引导 |

### 正文标题层级

| 层级 | 编号格式 | 字体 | 字号 | 示例 |
|------|---------|------|------|------|
| 一级标题 | 一、二、三、 | 黑体 | 三号（16pt） | 一、经营概况 |
| 二级标题 | （一）（二）（三） | 楷体_GB2312 | 三号（16pt） | （一）核心指标 |
| 三级标题 | 1. 2. 3. | 仿宋_GB2312 | 三号（16pt） | 1. 水费收入 |
| 四级标题 | （1）（2）（3） | 仿宋_GB2312 | 三号（16pt） | （1）居民用水 |

### 正文

| 元素 | 字体 | 字号 | 备注 |
|------|------|------|------|
| 正文 | 仿宋_GB2312 | 三号（16pt） | 中文默认字体 |
| 英文 / 数字 | Times New Roman | 三号（16pt） | 与中文字号匹配 |
| 表格内文字 | 仿宋_GB2312 | 小四（12pt） | 表格内可适当缩小 |
| 页码 | 宋体 | 四号（14pt） | 居中，格式"— X —" |

## 编号规范

### 中文编号体系（正文使用）

| 层级 | 格式 | 示例 |
|------|------|------|
| 第一层 | 汉字加顿号 | 一、二、三、四、 |
| 第二层 | 汉字加全角括号 | （一）（二）（三） |
| 第三层 | 阿拉伯数字加下脚点 | 1. 2. 3. |
| 第四层 | 阿拉伯数字加全角括号 | （1）（2）（3） |

### 编号使用规则

- 一级标题（"一、"）后**不加空格**，直接接标题文字
- 二级标题（"（一）"）后**不加标点**，直接接标题文字
- 三级标题（"1."）后**加空格**，接正文
- 编号层级不可跳级（如一之后不能直接接 1.）

## 表格规范

| 参数 | 规范 |
|------|------|
| 表格样式 | 三线表（顶线、栏目线、底线） |
| 表头 | 加粗，居中 |
| 表内文字 | 仿宋_GB2312，小四（12pt） |
| 数字对齐 | 右对齐，小数点对齐 |
| 金额单位 | 统一标注在表头右上角 |
| 空单元格 | 填"—"，不留空白 |
| 续表 | 标注"续表"，表头重复 |

---

## 图表规范

| 参数 | 规范 |
|------|------|
| 配色 | 黑白灰为主，适合公文打印 |
| 图题 | 图下方居中，宋体小四 |
| 表题 | 表上方居中，宋体小四 |
| 字体 | 图内文字使用宋体或黑体 |
| 尺寸 | 不超过版心宽度 |

---

## 页码与版面

| 参数 | 规范 |
|------|------|
| 位置 | 页面底端居中 |
| 格式 | — X —（X 为页码） |
| 字体 | 宋体，四号（14pt） |
| 起始页 | 正文第 1 页 |
| 附件页码 | 与正文连续编排 |

## 格式规范

| 维度 | 规范 |
|------|------|
| 适用标准 | GB/T 9704-2012《党政机关公文格式》 |

## 调用说明

所有 L2 模板在生成 docx 报告时引用本规范：
1. 页面设置：读取"页面设置"章节参数
2. 字体映射：读取"字体与字号"章节，按元素类型匹配字体
3. 段落格式：读取"段落格式"章节，设置首行缩进和行距
4. 编号生成：读取"编号规范"章节，按层级自动编号
5. 表格样式：读取"表格规范"章节，生成三线表
6. docx 参数：读取"docx 生成参数"章节的 JSON，直接用于 python-docx / docxtemplater 等库

各 L2 模板的"格式规范"表格中引用本规范：
> 参照 `[L2:GB/T 9704-2012 公文格式规范]`
