# 月度经营分析报告模板

> 效力等级：L2 形式规范 · 格式骨架
> 适用：月度经营分析报告生成
> 版本：v1 · 2026-07-30
> 引用依据：依据公司《财务管理办法》经营分析章节（具体条款号待补）

---

## 模板说明

本模板为月度经营分析报告的**格式骨架**，规定章节结构与表格样式。
内容与流程由 L1 规则库约束；判断方法可参考 L3 案例库。

---

## 报告格式骨架

### 标题区

```
[公司名称] [年] [月]度经营分析报告

编制部门：财务部
编制日期：[YYYY-MM-DD]
密级：内部
```

### 正文结构

#### 一、经营概况

**表格：主要经营指标完成情况**

| 指标 | 单位 | 本月预算 | 本月实际 | 差异 | 执行率 | 上月实际 | 环比变动 |
|------|------|---------|---------|------|--------|---------|---------|
| 营业收入 | 万元 | | | | | | |
| 营业成本 | 万元 | | | | | | |
| 利润总额 | 万元 | | | | | | |
| 经营现金流 | 万元 | | | | | | |

- 累计完成情况（年度累计执行率）
- 总体评价（一句话结论先行）

#### 二、收入分析

- 水费收入（售水量 / 平均单价 / 收入）
- 工程收入 / 其他业务收入
- 收入变动主要原因（量价分解）
- 收入预算执行情况

#### 三、成本费用分析

- 供水成本构成（动力费 / 药剂费 / 人工 / 折旧 / 管网维护）
- 期间费用（管理费用 / 财务费用 / 税金及附加）
- 成本变动主要原因
- 成本预算执行情况

#### 四、利润分析

- 利润总额 / 净利润
- 同比变动 / 环比变动
- 变动原因（收入驱动 / 成本驱动 / 营业外因素）
- 利润预算执行率

#### 五、资金状况

- 现金流（经营活动 / 投资活动 / 筹资活动）
- 应收账款情况（余额 / 账龄 / 回款情况）
- 重大资金收支事项
- 融资与债务情况（含化债注资进度，按 L1 脱敏清单处理）

#### 六、预算执行

- 收入预算执行率
- 支出预算执行率
- 重大差异说明（差异率 > 10% 须解释）
- 全年预算完成预测

#### 七、存在问题与建议

- 本月发现的主要问题（按重要性排序）
- 管理建议（结论先行，附依据）
- 下月重点工作提示

#### 八、附录

- 关键指标明细表
- 异常事项说明（校验标记的异常项）
- 审计三段（仅 T3/T4 风险等级输出，按 L1 权限分级规范）

## 调用说明

数据分析师产出分析结论 + 图表后，报告撰写员引用本模板生成正式报告：
1. 读取本模板骨架
2. 填入数据分析师的分析结论
3. 按 L1 规则库约束校验内容完整性
4. 执行校验收尾（勾稽 / 口径 / 格式）
5. 按预设脱敏方案处理
6. STOP gate：报送口径确认（如预算 vs 实际 / 同比 vs 环比）
