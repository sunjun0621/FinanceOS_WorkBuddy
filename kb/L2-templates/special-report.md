# 专项财务分析报告模板

> 效力等级：L2 形式规范 · 格式骨架
> 适用：化债注资 / 水价调整 / 重大投资 / 资产处置 / 专项资金等专项财务分析
> 版本：v1 · 2026-07-30
> 关联：`[L1:脱敏标准清单#三]`（水务专项脱敏）、`[L1:权限分级#二]`（风险分层）

---

## 模板说明

本模板为专项财务分析报告的**通用格式骨架**。通过"适配指引"适配不同专项场景，骨架不变、内容按场景填充。

与月度/季度模板的区别：月度/季度是**常规周期性报告**（固定结构、全口径），专项报告是**事项驱动型报告**（聚焦单一事项、深度分析、含风险评估与方案建议）。

---

## 报告格式骨架

### 标题区

```
[公司名称] [专项事项名称]专项财务分析报告

编制部门：财务部
编制日期：[YYYY-MM-DD]
密级：[内部 / 秘密，按事项涉密等级确定]
```

### 正文结构

#### 一、事项背景与分析目的

- **事项概述**：什么事项、何时发生、涉及金额、涉及主体
- **触发原因**：上级要求 / 主动发现 / 政策变动 / 事项到期
- **分析目的**：为决策提供财务依据 / 评估风险 / 满足报送要求
- **分析范围**：时间范围、口径范围、涉及部门

#### 二、现状与数据呈现

- **基本情况**：事项当前状态、已有进展
- **核心数据**：

**表格：专项事项核心数据**

| 维度 | 单位 | 数据 | 数据来源 | 备注 |
|------|------|------|---------|------|
| | | | | |

- **数据说明**：口径定义、数据截止日、特殊处理（如化债数据的脱敏处理）

#### 三、分析

- **归因分析**：事项变动的驱动因素分解
- **影响评估**：
  - 对利润的影响
  - 对现金流的影响
  - 对资产负债结构的影响
  - 对预算执行的影响
- **对比分析**（如适用）：方案对比 / 历史对比 / 同行业对比

#### 四、风险评估

- **风险识别**：按维度列出潜在风险

**表格：风险评估矩阵**

| 风险点 | 发生概率 | 影响程度 | 风险等级 | 风险提示 |
|--------|---------|---------|---------|---------|
| | 高/中/低 | 高/中/低 | 红/橙/黄 | |

- **合规风险**：是否涉及监管要求、审批权限、信息披露义务
- **财务风险**：对关键财务指标的影响是否超 `[L1:异常阈值标准]` 阈值
- **操作风险**：执行过程中可能遇到的障碍

#### 五、建议与方案

- **结论先行**：一句话核心建议
- **方案选择**（如有多方案）：

| 方案 | 优势 | 劣势 | 财务影响 | 建议优先级 |
|------|------|------|---------|-----------|
| | | | | |

- **实施路径**：分步骤建议、时间节点、责任部门
- **监控要点**：执行过程中需关注的指标和节点

#### 六、附件

- 数据明细表
- 引用依据清单（制度条款 / 政策文件 / 会议纪要）
- 审计三段（仅 Gate-H 风险等级输出，按 `[L1:权限分级#二]`）

## 适配指引

### 化债注资专项

| 章节 | 适配要点 |
|------|---------|
| 事项背景 | 注资来源、注资金额、置换债务明细、利率变动 |
| 现状 | 化债前后的债务结构对比、利息支出变动 |
| 分析 | 利息节约测算、资产负债率改善、现金流改善 |
| 风险评估 | 置换合规性、资金到位风险、后续偿债压力 |
| 建议 | 置换方案选择、资金使用安排、后续融资规划 |
| 脱敏处理 | 按 `[L1:脱敏标准清单#三]` 化债注资信息条款执行 |

### 水价调整专项

| 章节 | 适配要点 |
|------|---------|
| 事项背景 | 调价背景（成本变动 / 政策要求 / 监审结论） |
| 现状 | 当前水价、调价方案、影响范围 |
| 分析 | 调价对收入的影响测算、成本补偿充分性分析 |
| 风险评估 | 社会稳定风险、监审合规风险、舆情风险 |
| 建议 | 调价方案建议、听证准备、实施时间窗口 |
| 脱敏处理 | 水价监审材料按 `[L1:脱敏标准清单#三]` 不进入缓冲区，仅引用结论 |

### 重大投资专项

| 章节 | 适配要点 |
|------|---------|
| 事项背景 | 投资标的、投资金额、投资方式、预期回报 |
| 现状 | 投资标的财务状况、估值情况 |
| 分析 | 投资回报测算（NPV/IRR/回收期）、现金流影响 |
| 风险评估 | 投资风险、流动性风险、合规风险 |
| 建议 | 投资方案选择、资金安排、投后管理建议 |

### 资产处置专项

| 章节 | 适配要点 |
|------|---------|
| 事项背景 | 处置标的、处置原因、处置方式 |
| 现状 | 资产账面价值、评估价值、处置底价 |
| 分析 | 处置损益测算、对当期利润的影响 |
| 风险评估 | 国有资产流失风险、审批合规风险、税务影响 |
| 建议 | 处置方案建议、审批路径、税务筹划 |

| 维度 | 规范 |
|------|------|

## 调用说明

1. 确定专项类型 → 查"适配指引"选择对应场景
2. 读取本模板骨架 → 按适配要点调整章节内容
3. 数据分析师产出分析结论 + 风险评估
4. 报告撰写员填入结论 → 引用本模板生成正式报告
5. 执行校验收尾（勾稽 / 口径 / 格式 / 脱敏 / 合规）
6. STOP gate：
   - Gate-H 风险：脱敏确认 + 报送内容确认
   - Gate-H 严格子级：完整审计三段 + 每步 gate + 决策日志入 L4
