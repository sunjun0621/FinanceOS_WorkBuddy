## 二、角色编排

| 阶段 | 角色 | 职责 |
|------|------|------|
| 感知 | 数据分析师 | 取数 + 阈值比对 + 异常标注 |
| 研判 | 数据分析师 | 分色定级 + 归因深度判定 |
| 执行 | 报告撰写员 | 套L2模板出稿 |
| 校验 | 数据分析师 | 勾稽/异常/口径/格式四维校验 |
| 交付 | 报告撰写员 | 按风险等级处理脱敏/输出 |
| 沉淀 | 知识管家 | 经验入L3，更新L2.5 |

**编排特点**：数据分析师承担三段（感知+研判+校验），报告撰写员承担两段（执行+交付），知识管家收尾。角色切换最少化，减少Token开销。

## 三、分阶段执行路径

### Phase 1：感知阶段

**输入**：月度预算+实际数据（JSON / 表格 / 口述）

**步骤**：
1. 数据入缓冲区：`数据缓冲区/{日期}_月度预算执行分析_{月份}数据/`
2. 读 `[L1:异常阈值标准]`，对缓冲区数据做分科目双轨阈值比对
3. 产出异常标注清单（格式见下）

**异常标注清单格式**：
```
| 科目 | 预算 | 实际 | 差异 | 绝对值阈值 | 比例阈值 | 触发? | 初判颜色 |
```

**数据需求**：
- 当月：预算 vs 实际（全部科目）
- 趋势上下文：前2个月实际数据（用于连续月判定）
- 特殊事项：化债进度/补贴拨付/政策变动/突发事件

**数据不足处理**：
- 缺前2月数据 → 只做月度标注（黄色），不做趋势判定
- 缺预算数 → 标注「无预算基准」，只做环比分析
- 缺特殊事项 → 询问总监补充

### Phase 2：研判阶段

**输入**：异常标注清单 + 趋势上下文

**步骤**：
1. 按 `[L1:异常阈值标准#4.1判定矩阵]` 对每项标注做分色定级
2. 检查特殊规则适用性：
   - 旺季(6-9月)？→ 电费/药剂费/泵站电费季节性豁免降级
   - 政策变动？→ 标注「政策性」后降级
   - 单笔>50万非经常性？→ 标注「一次性」剥离
   - 化债相关？→ 标注「化债」单独追踪
   - 补贴延迟？→ 剥离后单独标注「时间性差异」
3. 确定归因深度：
   - 🟡黄色：简要归因（1-2句）
   - 🟠橙色：深度归因（原因链+趋势预测+改进建议）
   - 🔴红色：仅汇总+标注，不自动出结论，强制人工确认
4. 产出研判结论（颜色汇总表 + 归因要点）

**研判结论格式**：
```
## 预警汇总
| 指标/科目 | 偏离 | 颜色 | 归因 | 建议 |
```

### Phase 3：执行阶段

**输入**：研判结论 + 缓冲区数据

**步骤**：
1. 读 `[L2:月度经营分析模板v1]`
2. 按模板八章节出稿：
   - 一、执行摘要（结论先行：利润达标?+核心风险1句话）
   - 二、水量与产销差分析（含趋势判定表）
   - 三、收入分析（分项对比）
   - 四、成本分析（分科目+阈值判定+归因）
   - 五、利润与现金流
   - 六、核心指标预警汇总（颜色表）
   - 七、特殊事项（化债/补贴/旺季/政策）
   - 八、改进建议（按优先级排序）
3. 引用规范：阈值引用 `[L1:异常阈值标准#x.x]`，模板引用 `[L2:月度经营分析模板v1]`

**产出**：报告初稿 → 存缓冲区 `/{任务目录}/output/`

### Phase 4：校验阶段

**输入**：报告初稿

**四维校验清单**：
| 维度 | 检查项 | 通过条件 |
|------|--------|---------|
| 勾稽 | 收入差异Σ = 成本差异Σ + 利润差异 | 等式成立 |
| 勾稽 | 月度数据Σ = 季度合计（如有季度数据） | 等式成立 |
| 异常 | 所有超阈值标注均已归因 | 无遗漏 |
| 异常 | 颜色判定与判定矩阵一致 | 无矛盾 |
| 口径 | 数据来源标注完整 | 有来源说明 |
| 口径 | 模拟/实际数据标注清楚 | 有标注 |
| 格式 | 报告结构符合L2模板 | 八章节齐全 |
| 格式 | 引用格式规范 | [L1/L2/L3:xxx] |

**校验结果**：通过 → 进交付；未通过 → 回执行阶段修改（最多2轮重试）

### Phase 5：交付阶段

**按风险等级处理**：
| 等级 | 脱敏 | 审计三段 | 输出方式 |
|------|------|---------|---------|
| Gate-M 内部分析 | 否 | 不输出 | 直接交付总监 |
| Gate-H 对外报送 | 是 | 输出 | 按报送格式转换 |
| Gate-H 重大决策（严格子级） | 是 | 输出+STOP gate | 总监确认后输出 |

**默认**：Gate-M 内部分析，不脱敏，直接交付。

### Phase 6：沉淀阶段

**步骤**：
1. 提炼可复用经验 → 写入 L3 案例库
2. 检查是否有新的阈值调整建议 → 更新 L1（需总监确认）
3. 检查编排路径是否有变化 → 更新本模板
4. 若同类任务累计≥3次 → 按 §七升版条件校验升版

## 六、升级与适配

### 6.1 升级为季度分析
- 复用月度标注结果，增加同比/YTD/趋势/季节性/全年预测板块
- 套用 `[L2:季度财务分析报告模板v1]`
- 参见 `[L3:季度财务分析_案例003]`

### 6.2 适配专项分析
- 化债注资/水价调整/重大投资/资产处置等专项场景
- 套用 `[L2:专项财务分析报告模板v1]`
- 编排路径：感知(专项数据)→研判(专项指标)→执行(专项模板)→校验→交付→沉淀

### 6.3 风险等级升级
- Gate-M→Gate-H（对外报送）：增加脱敏处理 + 审计三段输出
- Gate-H→Gate-H严格子级（重大决策）：增加 STOP gate + 总监逐项确认
