# 月度预算执行分析 · 案例 001

**日期**：2026-07-30
**场景**：市属水务企业月度预算执行分析
**风险等级**：T2 分析研究

## 问题
月度预算执行分析——对比预算与实际，识别差异原因，提出改进建议。

## 方法
1. **感知阶段**：从数据缓冲区取预算与实际数据（JSON 结构化）
2. **研判阶段**：差异分解为收入端和成本端，按绝对值排序聚焦 TOP3；异常指标预设阈值（产销差率 >0.5pp 偏离、水费回收率 >2pp 偏离、单项成本差异 >60 万）自动报红
3. **执行阶段**：套 L2 模板（八大章节），报告撰写员出稿，数据分析师校验收尾（勾稽/异常/口径/格式，1 轮通过）
4. **交付阶段**：T2 内部分析，不脱敏、不输出审计三段
5. **沉淀阶段**：经验入 L3，编排路径待≥3 次后入 L2.5

## 结果
- 报告产出：`tasks/2026-07-30_月度预算执行分析/output/2026年7月预算执行分析报告.md`
- 编排耗时：5 阶段串行，0 次阶段回退，0 次 STOP gate 打断（内部分析预设方案自动通过）
- 校验：1 轮通过，0 个未通过项

## 可复用点
1. **差异分解法**：利润差异 = 收入端差��（Σ各项收入差异）+ 成本端差异（Σ各项成本差异），双维度归因
2. **水务专项指标阈值**：产销差率偏离 >0.5pp 报红、水费回收率偏离 >2pp 报红、单项成本差异 >60 万标注（可按公司实际调整阈值）
3. **补贴收入的处理**：政府补贴延迟拨付属时间性差异，研判时单独剥离（"扣除后实质净利润"），避免误判为趋势性收入下降
4. **编排模式**：数据分析师（感知+研判+校验收尾）→ 报告撰写员（执行）→ 知识管家（沉淀），可复用
