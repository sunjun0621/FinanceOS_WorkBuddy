# 月度预算执行分析 · 案例 002

**日期**：2026-07-30
**场景**：市属水务企业月度预算执行分析（6月·旺季）
**风险等级**：T2 分析研究
**数据来源**：基于公开水务成本监审数据构造的模拟数据

## 问题
6月预算执行分析——旺季场景，验证 L1 异常阈值标准 v1 的分项阈值、季节性豁免、趋势性判定三大机制是否有效运作。

## 方法
1. **感知阶段**：构造 6 月模拟数据（JSON），含 5 月/4 月趋势上下文；读 `[L1:异常阈值标准]` 对缓冲区数据做分科目双轨阈值比对 → 产出异常标注清单（6 个科目标注）
2. **研判阶段**：按 `[L1:异常阈值标准#4.1判定矩阵]` 分色定级
   - 产销差率：4月正常→5月超阈值→6月超阈值 = 连续2月同方向 → 🟠橙色
   - 制水电费：超绝对值+比例阈值，但6月属旺季 → 季节性豁免降级 → 🟡黄色
   - 药剂费：超阈值，汛期浊度升高致投加量增加 → 🟡黄色
   - 管网维护费：达阈值，含18万爆管一次性 → 剥离后日常维护低于预算 → 🟡黄色(标注一次性)
   - 资产负债率：偏离年末目标2.3pp → 🟡黄色(化债资金未到位)
3. **执行阶段**：套 `[L2:月度经营分析模板v1]` 八章节出稿；化债利息变化按特殊规则单独追踪
4. **校验阶段**：数据分析师校验（勾稽：收入差异Σ=成本差异Σ+利润差异 ✓；异常：6项标注全部归因；口径：模拟数据标注来源；格式：模板合规）→ 1轮通过
5. **交付阶段**：T2 内部分析，不脱敏
6. **沉淀阶段**：经验入 L3（本案例）

## 可复用点

### 1. 阈值系统三机制验证通过
| 机制 | 测试场景 | 结果 | 结论 |
|------|---------|------|------|
| 分项双轨阈值 | 制水电费超±30万/±8% | 正确触发 | ✅ 绝对值+比例双轨有效 |
| 季节性豁免 | 6月旺季电费降级 | 橙→黄正确降级 | ✅ 规则有效，避免假阳性 |
| 趋势性判定 | 产销差率连续2月超阈值 | 黄→橙正确升级 | ✅ 判定矩阵有效 |

### 2. 一次性 vs 趋势性判定实操要点
- **爆管维修费(18万)**：单笔>50万才算大额一次性，18万不满足剥离条件，但归因时标注「一次性·爆管」有助于研判。建议：将大额一次性阈值从50万下调至15万（中型水务企业口径），或在归因环节增加「单笔>10万且非经常性」的标注规则。
- **药剂费(汛期水质)**：属外部环境驱动而非管理问题，归因为「水质驱动·合理增长」。但连续2月超阈值仍需升级——7月若汛期持续，药剂费可能从黄→橙。

### 3. 化债专项追踪机制
- 利息支出下降5万，系化债置换部分执行。按 `[L1:异常阈值标准#4.2规则4]` 单独追踪，不与常规利息合并趋势判定。
- 实操问题：化债置换是渐进过程（非一次性完成），月度间利息变化不均匀。建议在 L1 增加「化债置换进度台账」字段，记录每月置换金额/利率变化/节约利息，便于月度环比和累计效果测算。

### 4. 产销差率橙色预警的处置路径
- 当前判定：连续2月超阈值 → 🟠橙色 → 通知+深度归因+改进建议
- 处置建议已写入报告第七节：7月重点区域漏损排查 + DMA建设加速
- 预警跟踪规则：若7月仍超阈值 → 连续3月 → 🔴红色 → 强制人工确认 + 考虑调整预算基准
- **关键经验**：橙色预警不应只停留在报告标注，需在改进建议中明确「下一步升级条件和时限」
