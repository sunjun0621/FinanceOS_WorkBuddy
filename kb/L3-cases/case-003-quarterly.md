**日期**：2026-07-30

**风险等级**：T2 分析研究
**数据来源**：基于公开水务成本监审数据构造的模拟数据

## 问题
Q2季度财务分析——验证季度财务分析报告模板 v1 的六大差异板块（同比/趋势/季节性/YTD/全年预测/风险矩阵）是否有效，以及 L1 异常阈值标准在季度口径下的适用性。

## 方法
1. **感知阶段**：构造 Q2 模拟数据（含月度明细+去年同期+Q1数据+全年预算），读 `[L1:异常阈值标准]` 做季度口径阈值比对
2. **研判阶段**：
   - 同比分析：Q2 2026 vs Q2 2025，收入+4.3%/成本+3.7%/利润+5.9%(扣除补贴+17.8%)
   - 趋势研判：Q1→Q2 产销差率 14.29%→15.57%，环比恶化1.28pp；月度逐月恶化(4月正常→5月黄→6月橙)
   - 季节性：Q2旺季起步，供水量环比Q1+10.4%，电费/药剂费压力上升
   - YTD：H1收入完成50.7%/成本49.1%/利润55.7%，均快于或接近时间进度
   - 全年预测：基于H1实际+化债到位预判，全年利润7,400-7,600万(完成预算103-106%)
3. **执行阶段**：套 `[L2:季度财务分析报告模板v1]` 九章节出稿
4. **校验阶段**：勾稽(月度Σ=季度 ✓/同比基数一致 ✓/YTD=Q1+Q2 ✓)、异常(趋势预警3项)、口径(补贴时间性差异剥离 ✓)、格式(模板合规含差异对照表 ✓) → 1轮通过
5. **交付阶段**：T2 内部分析
6. **沉淀阶段**：经验入 L3（本案例）

### 2. 季度口径 vs 月度口径的阈值适配问题

**发现问题**：L1 异常阈值标准的阈值是月度口径（如"制水电费 ±30万/±8%"），季度合计时绝对值阈值需要×3，但比例阈值不变。

**处理方式**：季度分析时，比例阈值直接适用（±8%不变），绝对值阈值按季度调整（×3）。但更优做法是**季度分析以月度标注为基础**——先做月度分项标注，再汇总到季度看趋势，而非直接对季度合计做阈值判定。

**建议**：在 L1 异常阈值标准增加一条说明：「阈值以月度为基础口径；季度/年度分析时，先做月度标注再汇总趋势，不直接对合计数做绝对值阈值判定」。

### 3. 补贴时间性差异的季度处理

月度案例中补贴延迟只影响单月利润判定，季度分析中影响更大——Q2去年同期含已拨付补贴200万，本季120万未拨付，直接同比会失真。

**处理规则验证**：按 `[L1:异常阈值标准#4.2规则5]` 剥离后，同比利润从+5.9%修正为+17.8%，差异显著。**季度分析必须执行补贴剥离**，不能仅标注。

### 4. 全年预测的假设管理

预测基于3个关键假设：①化债8月到位 ②Q3产销差率可控 ③无重大突发事件。每个假设变化对利润影响50-200万不等。

**经验**：全年预测应在报告中明确列出假设条件和敏感性区间，而非给出单一数字。本报告采用区间预测（7,400-7,600万），比点预测更稳健。

### 5. 季度报告与月度报告的编排差异

| 维度 | 月度报告(case002) | 季度报告(case003) |
|------|-----------------|-----------------|
| 数据量 | 单月+前2月趋势 | 3月明细+去年同期+Q1+全年预算 |
| 阈值比对 | 直接对月度数据 | 先月度分项→再汇总趋势 |
| 归因深度 | 单科目归因 | 同比+环比+趋势三维度 |
| 预测 | 无 | 全年预测(含假设管理) |
| 报告篇幅 | ~2000字 | ~3500字 |
| Token消耗 | 中 | 高(需加载历史期数据) |

**编排建议**：季度分析可在月度分析基础上增量产出——复用月度标注结果，增加同比/YTD/预测板块，避免重复计算。
