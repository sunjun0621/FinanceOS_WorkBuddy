# 预算执行差异归因 · 案例 006

**日期**：2026-07-30
**场景**：国企月度/季度预算执行分析中，需对预算差异进行系统化分解，区分数量因素和价格因素，给出管理建议
**风险等级**：T2 分析研究
**数据来源**：预算表、实际执行数据、业务量数据

## 问题
预算执行出现差异——分解差异原因，区分数量因素和价格因素，评估影响程度，给出针对性的管理建议。

## 方法
1. **第一步：计算差异**
   - **绝对差异** = 实际数 - 预算数
   - **相对差异** = 绝对差异 / 预算数 × 100%
   - **差异方向**：正差异（超预算）vs 负差异（低于预算）
   - 须同时看当月和累计，避免单月波动误判

2. **第二步：分解差异因素——数量/价格双因素模型**
   - **收入类差异**：
     ```
     收入差异 = 实际收入 - 预算收入
              = (实际数量 × 实际价格) - (预算数量 × 预算价格)

     数量因素 = (实际数量 - 预算数量) × 预算价格
     价格因素 = (实际价格 - 预算价格) × 实际数量
     ```
   - **成本类差异**：
     ```
     成本差异 = 实际成本 - 预算成本
              = (实际数量 × 实际单价) - (预算数量 × 预算单价)

     数量因素 = (实际数量 - 预算数量) × 预算单价
     价格因素 = (实际单价 - 预算单价) × 实际数量
     ```
   - 注意：数量因素和价格因素的计算顺序会影响结果，通常先算数量因素

3. **第三步：归因分析**
   - **数量因素归因**：外部因素（市场需求变化、政策影响）、内部因素（产能变化、销售策略调整）、季节性因素（历史同期对比）
   - **价格因素归因**：外部因素（原材料价格波动、市场价格竞争）、内部因素（产品结构调整、定价策略变化）、政策因素（税率调整、政府定价）

4. **第四步：评估影响程度**
   - **重大差异**：相对差异 > 10% 或绝对差异 > 预算总额的 5%
   - **一般差异**：相对差异 5%-10%
   - **正常波动**：相对差异 < 5%
   - 可引用 `[L1:异常阈值标准]` 做分项阈值比对

5. **第五步：给出管理建议**
   - **重大不利差异**：立即分析原因，提出纠偏措施
   - **重大有利差异**：分析原因，判断是否可持续
   - **一般差异**：持续关注，必要时调整预算
   - 关注差异的可持续性，一次性因素不纳入趋势判断

## 结果
- 差异计算总表：含绝对差异、相对差异、差异方向
- 数量/价格双因素分解表：各科目按数量因素和价格因素拆分
- 归因分析：各差异项的外部/内部/政策归因
- 影响程度评估：按重大/一般/正常波动分级
- 管理建议：按差异等级给出针对性措施

## 可复用点
1. **数量/价格双因素分解公式**：收入差异和成本差异均可拆分为数量因素和价格因素，公式通用，适用于所有预算科目
2. **影响程度三级分类**：重大（>10% 或 >5%预算总额）、一般（5%-10%）、正常波动（<5%），不同等级对应不同管理动作
3. **计算顺序约定**：先算数量因素（以预算价格为基准），再算价格因素（以实际数量为基准），保证分解结果一致性
4. **累计优先原则**：累计超支比当月超支更重要——单月波动可能正常，累计偏离才是真问题
5. **与 L1 阈值标准联动**：本方法的差异计算结果可直接输入 `[L1:异常阈值标准#4.1判定矩阵]` 做分色定级，实现标注→归因→建议的完整闭环
6. **编排路径**：取数（预算+实际）→ 差异计算 → 双因素分解 → 归因 → 影响评估 → 建议，可嵌入月度/季度分析流程

## 附：公益类国企收入执行差异归因（量价分解法的行业延伸 · 合并自 DuMate L3-CASE-001）

> 以下为 DuMate 公益类国企"收入执行差异归因"案例的精华合并。其方法本质与本案"数量/价格双因素模型"一致（量价分解法），故合并入本案例作为**行业延伸维度**，不单列。

### 附.1 收入差异的四维归因

公益类国企收入（如公共服务运输 / 供水 / 排水收入）受政府定价与水量驱动，在量价基础上额外引入"收缴率"与"季节性"两个行业维度：

| 序号 | 归因维度 | 说明 | 数据来源 |
|------|----------|------|----------|
| 1 | 水量波动 | 实际输送水量与预算测算水量的差异（降雨 / 区域用水量 / 季节） | 运营调度数据 |
| 2 | 定价调整 | 政府指导价或协议价格调整（政策性调价、合同续签重定价） | 价格批文 / 合同 |
| 3 | 收缴率变化 | 当期已确认收入与实际到账收入的差异（欠费 / 缓缴 / 坏账核销） | 财务应收台账 |
| 4 | 季节性因素 | 汛期水量增大、枯水期水量减少导致的收入季节性波动 | 历史月度数据 |

### 附.2 分解公式（量价 + 收缴率）

```
收入偏差 = 实际收入 - 预算收入
量差   = (实际水量 - 预算水量) × 预算单价
价差   = 实际水量 × (实际单价 - 预算单价)
收缴率差异 = 应收收入 × (实际收缴率 - 预算收缴率)
收入偏差 ≈ 量差 + 价差 + 收缴率差异 + 其他差异
```

> 与本案第二节"数量/价格双因素模型"对照：**量差≈数量因素、价差≈价格因素**，收缴率差异为国企收入特有补充项，使模型更贴合公益类国企实际。

### 附.3 判定规则（行业适配版）

| 偏差区间 | 判定 | 处置要求 |
|----------|------|----------|
| < ±10% | 正常 | 常规记录，纳入月度分析报告 |
| ±10% ~ ±30% | 需关注 | 启动归因分析，编制差异分解表，报送财务总监审阅 |
| > ±30% | 触发 STOP gate | 暂停后续预算执行审批，提交专项分析报告，经管理层确认后方可继续 |

**补充规则：**
- 连续 3 个月偏差方向一致（同为正 / 同为负）且均在 ±10%~±30% 区间，即使单月未超阈值，也应升级为"需关注"并启动趋势分析；
- 定价调整导致的价差，须附价格批文或合同变更依据，否则不纳入"正常"判定；
- 收缴率差异超过 5 个百分点，须单独编制应收账款账龄分析。

### 附.4 与本案衔接

- 收入类差异直接用本案第二节"数量/价格双因素模型"分解，再叠加本附的"收缴率 + 季节性"两维；
- 判定阈值统一引用 `[L1:异常阈值标准#4.1判定矩阵]`，收入类可改用本附.3 的行业阈值（±10%/±30%）；
- 公益类 / 商业类国企分类与考核口径见 `[L1:国资监管要求]`。
