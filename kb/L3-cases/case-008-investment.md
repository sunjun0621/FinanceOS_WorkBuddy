# 投资项目财务评价 · 案例 008

**日期**：2026-07-30
**场景**：国企新投资项目立项前财务评价、存量项目后评价、重大资产购置经济性论证
**风险等级**：T2 分析研究
**数据来源**：投资可行性报告、财务预测模型、行业基准数据

## 问题
国企投资项目财务评价——覆盖盈利能力、偿债能力、风险承受力三个维度，为投资决策提供量化依据，符合国资监管要求。

## 方法
1. **第一步：基础数据准备**
   - **投资总额**：建设投资 + 流动资金 + 预备费
   - **资金来源**：自有资金比例、融资方式、利率
   - **收入预测**：产品/服务定价、销量预测、收入时间分布
   - **成本预测**：固定成本、变动成本、税金
   - **项目周期**：建设期 + 运营期（通常 10-20 年）
   - 收入预测须有合理依据，不能过于乐观

2. **第二步：核心指标计算**

   | 指标 | 计算方法 | 判断标准 |
   |------|---------|---------|
   | 净现值（NPV） | 按基准折现率折现后净现金流累计 | NPV > 0 可行 |
   | 内部收益率（IRR） | 使 NPV=0 的折现率 | IRR > 基准收益率可行 |
   | 投资回收期 | 累计净现金流由负转正的时点 | 不超过行业基准期 |
   | 投资利润率 | 年均利润 / 投资总额 | 高于行业平均 |
   | 资产负债率 | 运营期年均负债/总资产 | 不超过 70%（国企红线） |

   - 国企投资项目的基准收益率通常取 **8%-10%**（参照国资委指引）
   - 自有资金比例须符合行业要求，通常 **不低于 30%**
   - 资产负债率 **D/A < 70%** 为国企红线

3. **第三步：敏感性分析**
   - 对关键变量做 ±10%~20% 的敏感性测试：
     - **收入下降**：测试收入减少 10%/20% 时 NPV 和 IRR 的变化
     - **成本上升**：测试成本增加 10%/20% 时 NPV 和 IRR 的变化
     - **工期延长**：测试建设期延长 6 个月/1 年的影响
     - **利率变动**：测试融资利率上升 1%/2% 的影响
   - 找出最敏感变量，评估项目抗风险能力
   - 敏感性分析至少覆盖 3 个关键变量

4. **第四步：风险识别**
   - **市场风险**：需求不达预期、价格竞争
   - **建设风险**：工期延误、投资超概算
   - **政策风险**：行业政策变化、环保要求提高
   - **融资风险**：资金不到位、利率上升
   - **运营风险**：技术不成熟、成本超预期

5. **第五步：形成评价结论**
   - 项目是否可行（量化依据）
   - 关键风险及应对措施
   - 需要关注的敏感性因素
   - 建议的决策条件（如"收入不低于 XX 时可行"）
   - 评价结论须注明关键假设，假设变化可能改变结论
   - 对外报送时按 `[L1:数据脱敏标准]` 处理项目信息

## 结果
- 核心指标计算表：NPV、IRR、投资回收期、投资利润率、资产负债率
- 敏感性分析表：各关键变量 ±10%/±20% 对 NPV 和 IRR 的影响
- 风险清单：按市场/建设/政策/融资/运营五类分级
- 评价结论：含可行性判断、关键假设、决策条件、风险提示

## 可复用点
1. **国企投资评价三阈值**：基准收益率 8%-10%、自有资金比例 ≥ 30%、资产负债率 D/A < 70%，三项为国资监管硬性约束
2. **五指标评价体系**：NPV（绝对价值）+ IRR（相对收益）+ 投资回收期（资金回笼）+ 投资利润率（盈利水平）+ 资产负债率（偿债安全），五维覆盖
3. **敏感性分析标准动作**：至少 3 个关键变量，±10%/±20% 两档测试，找出最敏感变量并评估抗风险能力
4. **结论必须含假设条件**：评价结论不能只给"可行/不可行"，须注明关键假设及其变化对结论的影响，给出决策边界条件
5. **前评 vs 后评价**：新项目投资前评价侧重预测合理性，存量项目后评价侧重实际 vs 可研对比，两者框架相同但数据来源不同
6. **编排路径**：数据准备 → 指标计算 → 敏感性分析 → 风险识别 → 结论，可引用 `[L2:专项分析报告模板]` 形成正式评价报告
