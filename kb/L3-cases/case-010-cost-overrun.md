# 成本费用超支归因 · 案例 010

**日期**：2026-07-30
**场景**：国企月度/季度预算执行分析中发现成本费用超支，需系统化归因并给出管理建议
**风险等级**：Gate-M 分析研究
**数据来源**：预算表、实际执行明细、合同台账、资产台账

## 问题
成本费用超支归因——区分超支的性质（一次性 vs 趋势性）、原因（内部 vs 外部）、可控程度，给出针对性的管理建议。

## 方法
1. **第一步：确认超支事实**
   - **绝对超支**：实际支出 > 预算支出
   - **相对超支**：超支金额 / 预算金额 > 10%
   - **累计超支**：累计执行率 > 时间进度 + 10%（如 7 月累计应执行 58%，实际已达 70%）
   - 须同时看当月和累计，避免单月波动误判

2. **第二步：按成本分类逐项分析**

   | 成本类型 | 超支常见原因 | 分析方法 |
   |---------|------------|---------|
   | 人工成本 | 人员增加、薪酬调整、加班费 | 对比编制人数 vs 实际人数，对比人均薪酬 |
   | 材料成本 | 用量增加、单价上涨、损耗率升高 | 分解量差和价差（参见 `[L3:case-006-budget-variance]`） |
   | 外委费用 | 新增委托、合同变更、单价调整 | 逐笔核对合同和结算 |
   | 管理费用 | 超标准开支、非经常性支出 | 逐笔核对，区分经常性和非经常性 |
   | 折旧摊销 | 新增资产、折旧方法变更 | 核对资产台账 |
   | 财务费用 | 融资增加、利率上升、汇率变动 | 分解融资规模因素和利率因素 |

3. **第三步：区分超支性质**（最关键判断步骤）

   | 性质 | 特征 | 处理方式 |
   |------|------|---------|
   | **一次性因素** | 非经常性、不可重复（如大修、诉讼、搬迁） | 说明原因即可，不纳入趋势判断，建议预算调整 |
   | **趋势性因素** | 持续性、会延续（如材料涨价、人员扩编） | 必须提出纠偏措施，评估全年影响 |
   | **季节性因素** | 周期性波动（如冬季供暖、夏季空调） | 对比历史同期，判断是否在合理范围 |
   | **政策性因素** | 政策变化导致（如社保基数调整、税率变化） | 计算政策影响金额，建议调整预算 |

4. **第四步：评估可控程度**

   | 可控程度 | 含义 | 管理建议 |
   |---------|------|---------|
   | 可控 | 管理层可通过决策改变（如招待费、差旅费） | 加强审批管控，压缩开支 |
   | 半可控 | 可通过管理手段缓解但无法完全消除（如材料损耗） | 设定标准，持续优化 |
   | 不可控 | 外部因素决定（如政策调整、市场价格） | 做好预案，适时调整预算 |

5. **第五步：形成归因结论**
   - 每项超支须回答**四个问题**：
     1. **超了多少？**（金额 + 差异率）
     2. **为什么超？**（具体原因，不是笼统的"成本增加"）
     3. **会持续吗？**（一次性 / 趋势性 / 季节性）
     4. **怎么办？**（纠偏措施 / 预算调整 / 持续关注）
   - 归因结论须有数据支撑，不能凭感觉判断原因

## 结果
- 超支确认表：含当月和累计超支金额、差异率、执行率
- 分项分析表：按人工/材料/外委/管理/折旧/财务费用逐项分析
- 性质判定：每项超支标注一次性/趋势性/季节性/政策性
- 可控程度评估：每项超支标注可控/半可控/不可控
- 归因结论：每项超支回答四问（超了多少、为什么、会持续吗、怎么办）

## 可复用点
1. **超支性质四分法**：一次性（非经常性，不纳入趋势）→ 趋势性（持续延续，必须纠偏）→ 季节性（周期波动，对比历史）→ 政策性（外部变化，调整预算），性质判定直接影响管理决策
2. **四问结论模板**：每项超支必须回答"超了多少 / 为什么超 / 会持续吗 / 怎么办"，避免笼统的"成本增加"式归因
3. **可控程度三分法**：可控（加强审批）→ 半可控（设定标准优化）→ 不可控（做好预案调预算），不同可控程度对应不同管理动作
4. **累计优先原则**：累计超支比当月超支更重要——累计执行率超过时间进度 +10% 才是真正的超支信号
5. **材料成本必须量价分拆**：不能笼统说"材料费超了"，须分解为量差（用量增加）和价差（单价上涨），分别归因（参见 `[L3:case-006-budget-variance]`）
6. **不要一刀切归为"管理不善"**：政策性因素和市场因素是客观存在的，归因须实事求是
7. **编排路径**：确认超支 → 分项分析 → 性质判定 → 可控评估 → 四问结论，可嵌入月度/季度预算执行分析的研判阶段
