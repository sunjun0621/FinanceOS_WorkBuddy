# 资本性支出差异归因 · 案例 011

**日期**：2026-07-31
**场景**：国企月度 / 季度预算执行分析中，资本性支出（设备购置、工程建设、信息化建设）偏差归因与进度风险评估
**风险等级**：Gate-M 分析研究
**数据来源**：资本性支出预算表、工程进度报告、采购管理台账、决算 / 结算对比表

## 问题
资本性支出执行偏差大、且月度波动剧烈——需区分"进度性差异"与"预算编制问题"，评估进度风险，给出针对性管理建议，避免误判为执行不力。

## 方法
1. **第一步：项目清单提取与分类**
   - 从资本性支出预算中提取所有项目，按"设备购置 / 工程建设 / 信息化建设"分类
   - 标注跨年项目及其预计完工时间

2. **第二步：逐项目偏差计算**
   - **偏差** = 实际 - 预算
   - **偏差率** = 偏差 / 预算 × 100%
   - 识别偏差主要来源项目（贡献最大的 1-2 项）

3. **第三步：偏差因素分解**
   - **进度延迟影响** = 延迟月数 × 月均计划产值
   - **预算精度影响** = 实际结算价 - 概算预算价
   - **政策变化影响** = 因政策调整新增 / 削减的支出（须单独列示，附政策依据）
   - 跨年项目按年度预算管理，单月偏差可通过后续月份追赶

4. **第四步：进度风险评估（独立于偏差判定）**
   - **月均执行压力** = 剩余预算 / 剩余月数
   - 对照阈值：< 月均预算 120% 低 / 120%~150% 中 / >150% 高
   - 已超支项目须提示预算调整程序

5. **第五步：汇总归因与判定**
   - 资本性支出偏差容忍度高于经常性支出：**±20%**（较经常性支出 ±5%~±10% 更宽松），但**进度滞后**须作为独立维度重点监控
   - 引用 `[L1:异常阈值标准]` 做分项阈值比对；超阈值触发 STOP gate（提交专项分析报告）

## 结果
- 项目级偏差分解表：每项目含预算 / 实际 / 偏差 / 归因
- 进度风险评估表：剩余预算 / 剩余月数 / 月均执行压力 / 风险等级
- 归因汇总：进度延迟 vs 预算精度 vs 政策变化 的占比
- 处置建议：继续跟踪 / 重点跟踪 / 启动预算调整 / 暂停新项目立项

## 可复用点
1. **容忍度分级**：资本性支出 ±20%、经常性支出 ±5%~±10%——不同性质支出适用不同阈值，避免"一刀切"误判。
2. **进度风险独立维度**：偏差率超阈值未必是问题，须叠加"月均执行压力"判断真实风险（进度滞后才是真问题）。
3. **政策变化单列**：因政策（政府采购 / 环保标准 / 审计整改）导致的偏差，须附依据、不并入"预算编制不精确"归因。
4. **跨年项目标注**：当年仅执行部分预算的，须在报告中注明"跨年项目"及预计完工时间，防止被误读为执行不力。
5. **与 L1 阈值 / L1 资金管理办法联动**：偏差结果输入 `[L1:异常阈值标准#判定矩阵]` 分色定级；资金支付节奏衔接 `[L1:资金管理办法#监控指标]`。
6. **编排路径**：提取项目清单 → 逐项目偏差 → 因素分解 → 进度风险评估 → 汇总归因 → 建议，可嵌入季度 / 年度分析流程。
