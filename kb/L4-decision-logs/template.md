# L4 决策日志 · 记录模板与规范

> 效力等级：L4 决策追溯 · 按风险分级强制/按需记录
> 适用：FinanceOS 运行闭环中 T3/T4 风险等级任务的决策点记录
> 版本：v1 · 2026-07-30
> 关联：`[L1:权限分级#二]`（风险分层）、cfo-command-center v4.1 第4节（协作模式）

---

## 一、记录触发规则

| 风险等级 | 是否记录 | 记录时机 | 记录人 |
|---------|---------|---------|--------|
| T1 日常查询 | 不记录 | — | — |
| T2 分析研究 | 不强制（总监要求时补） | 总监指定时 | AI 起草 → 总监确认 |
| T3 预算/报送 | **强制记录** | STOP gate 通过时自动触发 | AI 自动记录 |
| T4 审计/巡视 | **全量记录** | 每步 gate 触发 | AI 逐步记录 → 总监确认 |

---

## 二、单条决策记录格式

每条决策记录按以下结构填写，存为本目录下的 Markdown 文件：

```
文件名：DEC-[YYYYMMDD]-[序号]_[决策事项简述].md
示例：DEC-20260730-001_月度预算执行差异容忍度调整.md
```

### 记录模板

```markdown
# 决策记录 DEC-[编号]

**日期**：[YYYY-MM-DD]
**风险等级**：[T3/T4]
**决策事项**：[一句话描述决策内容]
**决策人**：[财务总监 / 授权人]
**关联任务**：[任务名或编号]

---

## 1. 决策背景

- [为什么要做这个决策？触发因素是什么？]
- [涉及的业务场景和数据范围]
- [关联的 L3 案例 / L4 历史决策]（如有引用）

## 2. 备选方案

| 方案 | 内容概要 | 优势 | 劣势 | 风险评估 |
|------|---------|------|------|---------|
| 方案A | | | | |
| 方案B | | | | |
| 方案C | | | | |

## 3. 选择依据

- **选择方案**：[方案X]
- **选择理由**：
  - [理由1，附数据/规则依据]
  - [理由2]
  - [理由3]
- **依据来源**：`[L1:xxx]` / `[L3:xxx]` / 总监判断 / 外部政策
- **约束条件**：[方案执行的前提条件/限制]

## 4. 执行结果

- **执行时间**：[YYYY-MM-DD]
- **执行情况**：[按计划执行 / 调整后执行 / 未执行（原因）]
- **实际效果**：[量化结果，如节约成本X万/执行率提升Xpp]
- **偏差说明**：[与预期的偏差及原因，如无偏差写"无"]

## 5. 事后验证

- **验证时间**：[YYYY-MM-DD]（通常为下一个周期）
- **验证结论**：[决策正确 / 部分正确 / 需修正]
- **验证依据**：[实际数据对比]
- **经验提炼**（满足任一即入库 L3）：
  - [ ] 用了与现有条目不同的方法且效果好 → 入 L3
  - [ ] 决策事后验证与预期不一致（反面经验）→ 入 L3 标注"反面"
  - [ ] 无新增经验 → 不入库

---

## 6. 审计追溯信息（仅 T4）

- gate 记录：[每步 gate 的时间/内容/通过状态]
- 修改记录：[决策过程中的修改痕迹]
- 移交内审：[是/否，移交时间]
```

## 三、字段填写规范

| 字段 | 规范 | 示例 |
|------|------|------|
| 决策编号 | DEC-YYYYMMDD-序号，序号每日从001起 | DEC-20260730-001 |
| 风险等级 | 仅填 T3 或 T4 | T3 |
| 决策事项 | 动宾结构，≤30字 | 批准月度预算执行差异容忍度从5%调至8% |
| 决策人 | 总监本人 / 授权人（注明授权范围） | 孙总监 / 张副总监（L2授权·分析范围） |
| 选择依据 | 每条理由须标注依据来源 | 依据 `[L1:异常阈值标准#4.2]` 季节性豁免规则 |
| 执行结果 | 量化为主，避免定性描述 | 节约利息支出约45万/月，资产负债率下降1.2pp |
| 事后验证 | 至少在下一个 reporting 周期验证 | Q3末验证Q2决策 |

## 四、引用方式

其他库/阶段引用决策日志时：

```
[L4:DEC-20260730-001]               # 引用整条决策
[L4:DEC-20260730-001#3.选择依据]     # 引用特定字段
[L4:DEC-20260730-001#5.经验提炼]     # 引用经验提炼结论
```

## 五、与运行闭环的衔接

```
研判阶段    → 读 L4 历史决策（引历史上下文，避免重复决策）
STOP gate   → T3/T4 决策通过时自动触发记录
沉淀阶段    → 事后验证结果写入 L4 + 经验提炼入 L3
主动认知层  → 红色预警触发决策时，记录入 L4
```
