# 预算差异归因 SKILL

> CFO 月末最高频任务 · 量价双因素分解

## 快速开始

对 AI 说：

> **用示例数据跑一次预算差异归因**

## 文件

- [SKILL.md](SKILL.md) — 技能指令（量价分解 + 归因路径）
- [examples/sample-data.json](examples/sample-data.json) — 2026 年 Q2 季度预算执行表（5 科目，含量价分解）

## 效果

输出：分科目对比表 + 颜色标注（正常/需关注/STOP gate）+ 量价归因链 + 改进建议。

**重点演示**：制水电费超支 171 万 → 量差 24 万（供水增加）+ 价差 147 万（电价上涨/单耗上升）→ 价差为主，建议 Q3 开展泵站能效诊断。

## 用自己的数据

把你的预算 vs 实际数据按 `examples/sample-data.json` 结构整理（含业务量、单价字段以支撑量价分解），粘贴给 AI 后说"预算差异"即可。
