# 预算差异归因

> 定位：CFO 月末最高频任务——"预算执行偏差归因"。输入预算 vs 实际数据，输出分科目对比 + 颜色标注 + 量价归因链 + 改进建议。

| 维度 | 说明 |
|------|------|

| 风险等级 | Gate-M 分析研究（默认内部分析） |
| 预期耗时 | 约 10-15 分钟 |

## 三、执行路径

### Phase 1 感知（差异计算）
1. 读 examples/sample-data.json
2. 计算各科目：绝对差异 = 实际 − 预算；相对差异 = 绝对差异 / 预算 × 100%；差异方向（超支/节约）
3. 累计优先原则：须同时看当月和累计，单月波动可能正常，累计偏离才是真问题

### Phase 2 研判（量价分解 + 归因）
1. **量价双因素分解**（引用 `[L3:case-006-budget-variance]` 第二节）：
   - 量差 =（实际数量 − 预算数量）× 预算单价
   - 价差 = 实际数量 ×（实际单价 − 预算单价）
   - 计算顺序：先算量差（以预算价格为基准），再算价差（以实际数量为基准）
2. **分色定级**（引用 `[L1:异常阈值标准#4.1判定矩阵]` + case-006 附.3 行业阈值）：
   - 正常（< ±10%）/ 需关注（±10% ~ ±30%，启动归因）/ 触发 STOP gate（> ±30%，暂停预算执行审批）
3. **归因**：
   - 量差归因：外部（需求/政策）、内部（产能/策略）、季节性
   - 价差归因：外部（原材料价格）、内部（结构调整）、政策（税率/政府定价）
4. **收入类**叠加"收缴率 + 季节性"两维（公益类国企，引用 case-006 附.1 四维归因）

### Phase 3 执行（出报告）
1. 差异计算总表：含绝对/相对/方向
2. 量价分解表：各重点科目按量差/价差拆分
3. 归因分析：外部/内部/政策
4. 影响程度评估：重大（>10% 或 >5% 预算总额）/ 一般（5-10%）/ 正常（<5%）
5. 管理建议：按差异等级给针对性措施（重大不利→纠偏；重大有利→判可持续性；一次性→剥离不入趋势）

### Phase 4 交付（Gate-M）
- 内部分析：不脱敏，直接交付
- 重大差异（>30%）且非一次性 → 升 Gate-H：STOP gate，暂停预算执行审批，提交专项分析

### Phase 5 沉淀
- 量价分解公式通用，适用于所有预算科目；编排路径入 L3

## 四、示例数据

见 [examples/sample-data.json](examples/sample-data.json)（2026 年 Q2 季度预算执行表，5 科目）。

**预埋重点**（用于演示量价分解）：
- 制水电费超支 +15%（差异 171 万 = 量差 24 万 + 价差 147 万）→ 需关注
- 药剂费超支 +22.9%（差异 48 万 = 量差 4.5 万 + 价差 43.5 万）→ 需关注，价差为主
- 维修费超支 +66.7%（差异 80 万，一次性大修）→ 剥离后不触发 STOP gate
- 化债利息节约 -10%（差异 -90 万）→ 正面趋势，单独追踪
