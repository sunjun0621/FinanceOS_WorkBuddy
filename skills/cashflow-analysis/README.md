# 现金流分析 SKILL

> 利润增长但现金流下降 · CFO 最警惕的信号

## 快速开始

对 AI 说：

> **用示例数据跑一次现金流分析**

## 文件

- [SKILL.md](SKILL.md) — 技能指令（三类差异分解 + 三分法归因 + 自我验证）
- [examples/sample-data.json](examples/sample-data.json) — 利润表 + 现金流简表（背离场景）

## 效果

输出六章节现金流分析报告，核心演示**利润-现金流背离归因**：
- 净利润同比 +8.1% vs 经营现金流同比 -15.0% → 背离
- 匹配度 65% < 80% → 预警
- 间接法分解：净利润 1154 + 折旧 60 − 营运资金占用 464 = 经营现金流 750
- 三分法归因：短期（旺季回款滞后）/ 结构（回收率降）/ 管理（催收不足）

## 用自己的数据

把利润表 + 现金流简表按 `examples/sample-data.json` 结构整理（含同期对比、营运资金变动），粘贴给 AI 后说"现金流分析"即可。
