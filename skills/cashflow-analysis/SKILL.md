# 现金流分析

> 定位："利润增长但现金流下降"是 CFO 最警惕的信号。输入利润表 + 现金流简表，输出经营/投资/筹资三活动分析 + 利润与现金流背离归因。

## 三、执行路径

### Phase 1 感知（取数 + 勾稽）
1. 读 examples/sample-data.json（利润表 + 现金流简表）
2. 三流量勾稽校验：经营 + 投资 + 筹资 = 现金及现金等价物净增加额（等式必须成立）
3. 间接法勾稽：经营现金流 = 净利润 + 折旧摊销 + 营运资金变动

### Phase 2 研判（背离分析，引用 `[L3:case-005-profit-vs-cashflow]`）
1. **确认背离**：净利润同比 vs 经营现金流同比，方向/幅度差异
2. **匹配度**：经营现金流 / 净利润，< 80% 启动差异分析（阈值来自 case-005）
3. **三类差异分解**：
   - 非现金项目：折旧摊销、资产减值、公允价值变动
   - 营运资金变动：应收增加（占用）、存货增加（占用）、应付减少（支付）
   - 非经营项目：投资收益、财务费用
4. **三分法归因**：
   - 短期因素（时间性差异，可自愈）
   - 结构因素（业务模式变化，需战略调整）
   - 管理因素（执行问题，需加强管控）
5. **自我验证**（dexter 范式）：交叉验证勾稽是否成立、趋势是否≥3-6 月、季节性是否已剔除

### Phase 3 执行（出报告，引用 `[L2:现金流分析模板]` 六章节）
1. 现金流总体概况（三流量总览 + 结构特征）
2. 经营活动现金流分析（收现质量：销售收现比、盈余现金保障倍数）
3. 利润与现金流背离分析（背离确认 + 差额分解 + 归因）
4. 投资与筹资活动分析（资本性支出 vs 预算，融资净流入）
5. 自由现金流与缺口预警（FCF = 经营现金流 − 资本性支出，引用 `[L1:资金管理办法#监控指标]`）
6. 结论与建议

### Phase 4 交付（Gate-M）
- 内部分析：不脱敏，直接交付
- FCF 持续为负 + 筹资能力下降 → 升 Gate-H：风险提示 + 总监确认

### Phase 5 沉淀
- 背离归因三分法经验入 L3；编排路径嵌入 `[L2.5:月度预算执行分析]` 研判阶段

## 四、示例数据

见 [examples/sample-data.json](examples/sample-data.json)（利润表 + 现金流简表，2026 年 6 月 vs 去年同期）。

**预埋背离**：
- 净利润同比 +8.1%（1154 万 vs 1068 万）
- 经营现金流同比 -15.0%（750 万 vs 882 万）
- 匹配度 65% < 80% → 预警
- 间接法勾稽：750 = 1154（净利润）+ 60（折旧）− 464（营运资金占用）✓
- 主因：应收账款增加 380 万（水费回收率 92%→89.5%）、应付减少 50 万
