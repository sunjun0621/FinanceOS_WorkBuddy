# 公文起草 SKILL

> 按 GB/T 9704-2012 起草报告/请示/函 · 国企 CFO 高频刚需

## 快速开始

对 AI 说：

> **用示例数据写一份化债资金请示**

或自定义：

> 帮我写一份关于 XX 事项的请示（附：申请金额/用途/还款计划）

## 文件

- [SKILL.md](SKILL.md) — 技能指令（6 步写作工作流 + 15 法定文种）
- [examples/sample-report.md](examples/sample-report.md) — "关于申请化债资金的请示"示范公文（含格式标注）

## 效果

输出符合 GB/T 9704-2012 的完整公文，含：
- 版头（发文机关 + 发文字号〔年份〕序号）
- 主体（标题三要素 + 主送机关 + 正文 + 落款）
- 版记（抄送 + 印发）
- 字体字号标注（方正小标宋/黑体/楷体/仿宋），便于转 Word

**重点演示**：请示文种——缘由（债务现状）+ 事项（金额/用途/还款）+ 风险防控 + 结语（妥否，请批示）。

## 支持的文种

15 法定公文：通知/通报/报告/请示/函/批复/决定/意见/通告/公告/议案/纪要/命令/决议/公报  
7 事务文书：工作总结/方案/讲话稿/汇报材料/简报/情况专报/回复函
