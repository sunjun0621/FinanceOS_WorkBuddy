# 公文起草（GB/T 9704）

> 定位：国企 CFO 高频刚需——按党政机关公文格式（GB/T 9704-2012）起草报告/请示/函。输入公文类型 + 核心内容要点，输出符合国标的公文（含版头/主体/版记）。

## 三、执行路径（6 步写作工作流，提取自 wenshu）

### Phase 1-2 感知 + 研判（识别场景 → 选文种）
1. **识别场景**：用户需求 → 公文类型。15 法定文种：通知/通报/报告/请示/函/批复/决定/意见/通告/公告/议案/纪要/命令/决议/公报；7 事务文书：工作总结/方案/讲话稿/汇报材料/简报/情况专报/回复函
2. **选文种**：文种混淆辨析（如报告 vs 请示：报告不要求批复，请示要求批复；请示一文一事，报告可一文多事）
3. **确认格式要素**（五层分类）：必备（标题/主送/正文/落款）/ 常见 / 条件项 / 地方样式 / 项目自定义——按需组合，避免无脑堆砌

### Phase 3 执行（按规范撰写，引用 `[L2:GB/T 9704-2012 公文格式规范]`）
1. **版头**：发文机关全称 + 发文字号（〔年份〕序号，六角括号〔〕，不用方括号[]）
2. **主体**：
   - 标题：三要素（发文机关 + 事由 + 文种），方正小标宋简体二号居中
   - 主送机关：左顶格，仿宋_GB2312 三号
   - 正文：仿宋_GB2312 三号（16pt），首行缩进 2 字符，行距 28 磅，两端对齐
   - 标题层级：一、（黑体三号）/（一）（楷体_GB2312 三号）/ 1.（仿宋三号）/（1）（仿宋三号）
   - 落款：发文机关全称 + 日期（阿拉伯数字），右空四字
3. **版记**：抄送机关 + 印发机关 + 印发日期
4. **编号铁律**：一、用顿号，1.用下脚点，不可混用；序号不编虚位（〔2026〕28号，非028号）
5. **语言四准则**：准确、简洁、庄重、得体

### Phase 4 交付（Gate-M → 对外升 Gate-H）
- 内部起草：Gate-M，直接交付
- 对外报送：升 Gate-H，全脱敏 + 判断决策必停 + 留痕

### Phase 5 沉淀
- 范文结构入 L3；wenshu 22 篇范文结构可作参考
