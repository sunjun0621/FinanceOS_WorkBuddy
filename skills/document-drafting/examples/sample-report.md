# XX水务集团有限公司关于申请化债专项资金的请示

</div>

<br>

市国资委：

&emsp;&emsp;为贯彻落实地方政府隐性债务化解工作部署，优化公司债务结构，降低财务成本，提升公共服务保障能力，现就申请化债专项资金事宜请示如下。

**一、公司债务现状**

&emsp;&emsp;截至2026年6月末，我公司银行借款余额12.8亿元，其中高息借款（年利率5.8%以上）余额3.2亿元，年利息支出约1856万元，财务负担较重，制约企业可持续发展。

（一）高息借款构成

&emsp;&emsp;高息借款主要为2019年至2021年管网改造专项贷款，利率区间5.8%至6.5%，期限5至8年，目前处于还本付息高峰期。

（二）化债工作进展

&emsp;&emsp;2026年上半年，我公司已通过自有资金置换高息借款1.2亿元，年节约利息约360万元。剩余高息借款3.2亿元拟通过申请化债专项资金予以置换。

**二、申请事项**

（一）申请金额

&emsp;&emsp;拟申请化债专项资金3亿元，专项用于置换剩余高息银行借款。

（二）资金用途

&emsp;&emsp;全部用于置换年利率5.8%以上的高息银行借款。置换后，公司综合融资成本预计由5.2%降至4.1%，年节约利息约330万元。

（三）还款计划

&emsp;&emsp;化债专项资金期限10年，前3年付息不还本，第4年起分7年等额还本。还款来源为自来水经营收入及污水处理费收入，年均经营现金流净额约8000万元，足以覆盖还本付息需求。

**三、风险防控**

&emsp;&emsp;1.建立化债资金专户，实行封闭运行、专款专用，确保资金不被挪用。

&emsp;&emsp;2.按月向市国资委报送化债进度及资金使用情况，接受全程监督。

&emsp;&emsp;3.将化债工作纳入年度经营考核，建立问责机制。

&emsp;&emsp;妥否，请批示。
