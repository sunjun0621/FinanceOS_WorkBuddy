# 财务知识问答

> 定位：轻量入口——CFO 随手问一个财务概念/政策/准则，AI 秒回。精准回答 + 引用 KB 来源标注。

## 一、任务定义

| 维度 | 说明 |
|------|------|
| 任务名称 | 财务知识问答 |
| 风险等级 | Gate-L 自动（纯读取，自动执行，仅异常报告） |
| 预期耗时 | < 30 秒 |
| 产出物 | 精准回答 + KB 来源标注 |
| 触发词 | `/ask`、什么是...、解释一下...、查一下... |
| 输入 | 自然语言提问（见 examples/sample-questions.md） |
| 模式 | 轻量模式（无产出物意图 → 直接执行，不启动角色编排） |

## 二、角色编排

| 阶段 | 角色 | 职责 |
|------|------|------|
| 感知 | 知识管家 | 解析问题，定位知识域（概念/政策/准则/阈值/流程） |
| 执行 | 知识管家（+政策研究员按需） | 检索 KB，组织回答 |
| 交付 | 知识管家 | 直接回答 + 来源标注 |

> Gate-L 轻量模式：不启动完整五阶段，直接检索回答。

## 三、执行路径

### Phase 1 解析问题
1. 识别问题类型：概念定义 / 政策解读 / 准则应用 / 阈值查询 / 流程说明
2. 提取关键词，定位知识域

### Phase 2 检索 KB（角色 Prompt 结构，提取自 awesome-chatgpt-prompts-zh）
1. **角色定义**：你是 FinanceOS 知识管家，精通国企财务规则/模板/案例
2. **知识边界**：只回答 KB 范围内的问题，超出范围如实标注
3. **检索顺序**：
   - 概念/术语 → `docs/glossary.md`
   - 规则/阈值 → `[L1 全部规则]`（8 条：脱敏/权限/异常阈值/输出/资金/成本/监管/科目）
   - 方法/经验 → `[L3 案例库]`（11 个案例）
   - 格式/模板 → `[L2 模板库]`
4. **回答规范**：精准 + 简洁 + 引用来源标注（如"来源：`[L1:异常阈值标准#2]`"）

### Phase 3 交付（Gate-L 自动）
- 直接回答，自动执行，仅异常报告
- 超出 KB 范围 → 标注"无历史参考"+ 风险提示，不臆测
- 涉及判断决策 → 提示"需总监确认"，不替总监判断（只发现不决策）
