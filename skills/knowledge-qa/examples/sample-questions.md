## 1. 什么是产销差率？预警阈值是多少？

**参考答案要点**：产销差率 =（供水量 − 售水量）/ 供水量，反映管网漏损与计量损失。预警阈值：偏离预算 > 0.5pp 触发标注（双轨触发：绝对值 + 比例）。

**来源**：`[L1:异常阈值标准#2核心财务指标阈值]` + `docs/glossary.md`

## 2. 化债资金怎么核算？

**参考答案要点**：化债置换导致利息支出变化，标注"化债"单独追踪，不与常规利息合并趋势判定；建议维护化债置换进度台账（月度置换金额/利率变化/节约利息）。化债节约利息属正面趋势。

**来源**：`[L1:异常阈值标准#4.2特殊规则-化债专项]` + `[L3:case-006-budget-variance]`

## 3. 资产负债率预警阈值是多少？

**参考答案要点**：资产负债率偏离年末目标 > 2pp 触发标注。颜色判定：单月超阈值 🟡 / 连续2月同方向 🟠 / 连续3月同方向 🔴。

**来源**：`[L1:异常阈值标准#2核心财务指标阈值]`

## 4. 什么是 STOP Gate？Gate-L/M/H/X 怎么区分？

**参考答案要点**：STOP Gate 是任务执行中的强制确认点，AI 必须停下来等总监确认。四级：
- Gate-L 自动：纯读取（查数字/问定义/检索），AI 自主执行
- Gate-M 确认后执行：分析计算（月度分析/差异/趋势），关键节点确认
- Gate-H 确认+脱敏+留痕：对外报送/审计巡视，判断决策必停
- Gate-X 禁止：删除/修改原始数据，拒绝执行（v2.4 新增禁止级）

**来源**：`docs/glossary.md` + `core/FINANCEOS_SYSTEM.md#4`

## 5. 利润增长但现金流下降说明什么？

**参考答案要点**：典型背离信号。匹配度 = 经营现金流 / 净利润，< 80% 启动差异分析。三类差异分解：非现金项目（折旧摊销）/ 营运资金变动（应收/存货/应付）/ 非经营项目。归因三分法：短期（时间性可自愈）/ 结构（业务模式变化）/ 管理（执行问题）。

**来源**：`[L3:case-005-profit-vs-cashflow]`

## 6. 预算差异归因的量价分解法怎么用？

**参考答案要点**：
- 量差 =（实际数量 − 预算数量）× 预算单价
- 价差 = 实际数量 ×（实际单价 − 预算单价）
- 计算顺序：先算量差（以预算价格为基准），再算价差（以实际数量为基准）
- 判定：正常 < ±10% / 需关注 ±10%~±30% / > ±30% 触发 STOP gate

**来源**：`[L3:case-006-budget-variance#2]`

## 7. 三色预警（黄橙红）分别对应什么动作？

**参考答案要点**：
- 🟡 黄色（单月超阈值，前2月正常）→ 报告中标注，不打断
- 🟠 橙色（连续2月同方向 / YTD 累计偏离）→ 主动通知总监 + 深度归因
- 🔴 红色（连续3月同方向）→ 强制通知 + 预暂停，须总监确认

**来源**：`[L1:异常阈值标准#5预警分级与动作映射]`

## 8. 公文标题的三要素是什么？

**参考答案要点**：发文机关 + 事由 + 文种。如"XX水务集团有限公司关于申请化债专项资金的请示"。标题用方正小标宋简体二号（22pt）居中，回行时词意完整。

**来源**：`[L2:GB/T 9704-2012 公文格式规范#字体与字号]`

## 9. 什么是数据缓冲区？为什么不沉淀？

**参考答案要点**：数据缓冲区是任务临时数据区，AI 只读即弃，不沉淀。铁律：缓冲区数字绝不进库。原因：AI 不拥有业务数据，数据通过缓冲区实时取用、用完即弃；存逻辑不存事实、能调度不包办。

**来源**：`core/FINANCEOS_SYSTEM.md#2` + `docs/glossary.md`

## 10. 双轴认知模型是什么？

**参考答案要点**：FinanceOS 核心模型。
- 横轴（角色轴 · 会什么）：数据分析师 / 报告撰写员 / 知识管家 / 预算管控官（按需）/ 政策研究员（按需）
- 纵轴（生命周期 · 怎么做）：感知 → 研判 → 执行（含校验收尾）→ 交付 → 沉淀
- 交叉点 = 工位；任务在角色×生命周期矩阵上自动编排，可跳阶段、可跨角色、同阶段可并行

**来源**：`core/FINANCEOS_SYSTEM.md#1` + `docs/glossary.md`
