# 月度经营分析 SKILL

> FinanceOS 旗舰演示技能 · 30 秒见效

## 快速开始

对 AI 说：

> **用示例数据跑一次月度经营分析**

## 文件

- [SKILL.md](SKILL.md) — 技能指令（五阶段执行路径 + KB 引用）
- [examples/sample-data.json](examples/sample-data.json) — 水务公司 6 月脱敏数据（含预埋异常）

## 效果

AI 自动读取示例数据，跑完五阶段（感知→研判→执行→交付→沉淀），输出：
- 八章节完整月度经营分析报告（经营概况/收入/成本费用/利润/资金/预算执行/问题建议/附录）
- 三色预警标注：5 个 🟡（产销差率/水费回收率/药剂费/维修费/咨询费）+ 3 个 🟠（电费/利润总额/经营现金流，连续2月趋势）
- 勾稽校验通过（收入差异Σ = 成本差异Σ + 利润差异）

## 用自己的数据

把你的月度数据按 `examples/sample-data.json` 的结构整理（含水量/收入/分科目成本/核心指标/特殊事项/前2月趋势），粘贴给 AI 后说"月度分析"即可。
