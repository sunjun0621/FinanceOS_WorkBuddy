# 月度经营分析

> 定位:用户安装后第一个试用的技能——必须 30 秒出效果。读示例数据,自动跑完五阶段,输出带 🟡🟠 颜色预警标注的完整八章节报告。

## 一、任务定义

| 维度 | 说明 |
|------|------|
| 任务名称 | 月度经营分析报告生成 |
| 风险等级 | Gate-M 分析研究（默认内部分析，不脱敏，关键节点确认） |
| 预期耗时 | 五阶段串行，约 15-20 分钟（含校验） |
| 产出物 | 月度经营分析报告（Markdown，八章节，含三色预警标注） |
| 触发词 | `/monthly`、月度经营分析、月度分析、帮我做月度经营分析 |
| 输入 | examples/sample-data.json（已内置）或用户粘贴的月度数据 |
| 模式 | 完整模式（含产出物意图 → 启动角色编排） |

## 二、角色编排

| 阶段 | 角色 | 职责 |
|------|------|------|
| 感知 | 数据分析师 | 取数 + 阈值比对 + 异常标注 |
| 研判 | 数据分析师 | 分色定级 + 归因深度判定 |
| 执行 | 报告撰写员 | 套 L2 模板出稿（八章节） |
| 交付 | 报告撰写员 | Gate-M 内部分析，不脱敏，直接交付 |
| 沉淀 | 知识管家 | 经验入 L3，更新 L2.5 |

> 编排特点：数据分析师承担三段（感知+研判+校验），报告撰写员承担两段（执行+交付），角色切换最少化，减少 Token 开销。

## 三、执行路径

### Phase 1 感知
1. 数据入缓冲区：读取 examples/sample-data.json（或用户数据）
2. 读 `[L1:异常阈值标准]`，对缓冲区数据做分科目双轨阈值比对（绝对值+比例）
3. 产出异常标注清单（科目 / 预算 / 实际 / 差异 / 阈值 / 触发? / 初判颜色）

### Phase 2 研判
1. 按 `[L1:异常阈值标准#4.1判定矩阵]` 分色定级：🟡黄（一次性）/ 🟠橙（连续2月同方向）/ 🔴红（连续3月）
2. 检查特殊规则适用性：
   - 旺季（6-9月）？→ 电费/药剂费季节性豁免降级（阈值上浮 20%）
   - 化债相关？→ 标注"化债"单独追踪，不与常规利息合并
   - 补贴延迟？→ 剥离标注"时间性差异"
   - 大额一次性（>50万）？→ 标注"一次性"剥离，不参与趋势判定
3. 确定归因深度：🟡 简要归因（1-2句）/ 🟠 深度归因（原因链+趋势+建议）/ 🔴 仅汇总待总监确认
4. 产出研判结论（颜色汇总表 + 归因要点）

### Phase 3 执行
1. 读 `[L2:月度经营分析模板v1]`
2. 按八章节出稿：经营概况 / 收入 / 成本费用 / 利润 / 资金 / 预算执行 / 问题建议 / 附录
3. 阈值引用 `[L1:异常阈值标准#x.x]`，模板引用 `[L2:月度经营分析模板v1]`
4. 报告中自然呈现 🟡 标注；🟠 主动通知；🔴 强制确认

### Phase 4 交付（Gate-M → 默认内部分析）
- 内部分析：不脱敏，不输出审计三段，直接交付总监
- 若对外报送 → 升 Gate-H：全脱敏 + 审计三段 + 判断决策必停

### Phase 5 沉淀
1. 提炼可复用经验 → 写入 L3 案例库
2. 编排路径有变化 → 更新 `[L2.5:月度预算执行分析]`
3. 同类任务累计 ≥3 次 → 校验升版

## 四、示例数据

见 [examples/sample-data.json](examples/sample-data.json)（水务公司 6 月脱敏数据）。

**数据结构**：meta + 水量 + 收入 + 分科目成本（制水/输配/污水/管理/财务）+ 税金 + 核心指标 + 特殊事项 + 前2月趋势。每项含 `{预算, 实际, 差异, 差异率}`。

**预埋异常**（用于演示预警效果）：
- 🟡 产销差率偏离 +0.7pp（>0.5pp，单月）
- 🟡 水费回收率偏离 -2.5pp（>2pp，单月）
- 🟡 药剂费超支 +22.9%（>10%）
- 🟡 维修费大修 +365%（一次性，剥离）
- 🟡 咨询费 +20万（一次性，查合同）
- 🟠 电费连续2月超支（6月旺季上浮后仍超）
- 🟠 利润总额连续2月偏离（-12%，>10%）
- 🟠 经营现金流连续2月偏离（-20%，>15%）
